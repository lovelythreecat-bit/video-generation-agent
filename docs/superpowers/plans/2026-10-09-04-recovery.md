# 重生成与恢复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在计划 1 的状态机和计划 2 的成片步骤上补上整条重生成、按镜头重生成、失败后续跑、自动退避、租约续期和不确定提交。

**Architecture:** 不新开一条生成流水线。`advance_generation(agent, work_id)` 仍是计划 1 的 `tick_once` 在 `kind=generation` 时调用的函数，签名不变。本计划整段替换计划 2 里需要改行为的步骤函数：按镜头时复用基础代的音轨和未替换片段，提交前处理相邻帧和不确定状态，导入时只重试下载，临时故障和短片段在原执行上退避。`hold_lease` 整段替换，测试用 `FrozenClock` 推进时间。规划分支、八种开关的混音和 `pad` 导出仍留在计划 1、计划 2 已有的函数里。

**Tech Stack:** Python 3.11、Pydantic v2、Pillow、pytest、标准库 `sqlite3` 与 `threading`、本机 `ffmpeg` / `ffprobe`。测试时钟只用 `FrozenClock`。

## Global Constraints

- Python 3.11+。运行时依赖只有 `pydantic>=2` 和 `pillow>=10`。测试依赖 `pytest`。SQLite、Tkinter、哈希和路径使用标准库。
- 可执行文件是本机 PATH 上的 `ffmpeg` 和 `ffprobe`。帧率 30。成片是 H.264、yuv420p 的 MP4。有音轨时是 AAC、48 kHz、立体声。
- 默认视频码率 8_000_000 bps，默认音频码率 192_000 bps。
- 时长档默认 `[5, 10, 15, 30]`，默认选中 10。每一档是 1 到 30 的整数，含 30。档位不可重复，列表不可空，默认档必须属于档位。
- 画面比例只有 `9:16`、`16:9`、`1:1`、`4:5`、`3:4`、`4:3`、`3:2`、`2:3`。对应默认尺寸是 1080×1920、1920×1080、1080×1080、1080×1350、1080×1440、1440×1080、1620×1080、1080×1620。
- 覆盖某一档尺寸时，宽和高都是正偶数，并且 `width * ratio_h == height * ratio_w`。不能增删比例档。
- `max_images` 的允许范围是 1 到 12。`max_file_bytes` 的允许范围是 1 到 20971520。等于默认值合法，大于默认值拒绝。
- 数据目录默认是进程当前目录下的 `.video-agent/`，环境变量 `VIDEO_AGENT_HOME` 可改。配置缺失时写入默认 `config.json`。配置读不出或违反规则时抛出错误，不改写原文件。
- 密钥只放在该目录的 `config.json`。仓库忽略 `.video-agent/`。
- 租约默认 60 秒，配置值不得低于 15 秒。自动退避只追加 2 次，常量名 `MAX_AUTO_RETRIES`。
- 配音语速只允许 0.5 到 2.0 倍。仍放不进已确认区间时，错误码是 `VOICEOVER_DOES_NOT_FIT`。
- 幂等记录只在状态写入成功的同一事务里插入。校验失败和状态冲突不写幂等记录。重放检查在状态判断之前。重放返回当时存下的 `TaskView`，不新建规划或视频执行。
- 帧数分摊并列时，改镜头列表里下标最小的镜头。
- 错误码只用规格里的表：`VALIDATION_ERROR`、`NOT_FOUND`、`STATE_CONFLICT`、`PLAN_VERSION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`FIRST_FRAME_NOT_IMPLEMENTED`、`VOICEOVER_DOES_NOT_FIT`、`SHOT_DURATION_SHORT`、`ASSET_MISSING`、`PROVIDER_TEMPORARY`、`PROVIDER_REJECTED`、`PROVIDER_SUBMISSION_UNCERTAIN`、`MEDIA_EXPORT_FAILED`。不新增错误码。
- 不引入 Agent 编排框架，不实现 HTTP，不实现首帧生图，不写真实供应商报文。

## 契约决议

计划 1、计划 2 已经定了下面这些内部名字。本计划沿用，不改公开方法、表名和字段名。

- `advance_generation(agent, work_id: str) -> str`。`VideoAgent.tick` 调用 `tick_once`。本计划不替换 `tick_once`，也不改规划分支。
- `MAX_AUTO_RETRIES` 在 `video_agent.lease`，值是 2。不要从 `video_agent.errors` 再定义一份。
- 数据库写事务只用 `agent.db.transaction()`。计划 1 的连接属性是 `_conn`，锁属性是 `_lock`。
- `confirm` 和 `retry_generation` 都调用 `_refresh_config()`，从磁盘重读 `config.json`。`snapshot_config` 的形状是 `{"mode", "adapters"}`。适配器额外字段放在该角色对象上，例如 `adapters.voice.marker`，不嵌在 `fields` 里。
- `retry_generation` 已经把 `auto_attempts_used` 置 0，并在没有任何 `external_task_id` 时重抄 `work_items.copied_config_json`。它不改 `generations.copied_config_json`。`generating_shots` 会把工作步骤设回 `submit_shot`。已提交未导入的镜头由本计划在步骤函数里收紧，不改 `service.py`。
- 计划 2 的 `_build_voice` 已按每个镜头的帧区间拒绝超过 2.0 倍的配音。本计划不替换 `_build_voice`、`_build_music`、`_step_visual`、`_step_export`。
- 供应商幂等键保持计划 2 的 `{generation_id}:{shot_id}`。

下面这些契约没有写死，用内部函数补上。

1. 计划 2 的 `_transaction` 已经委托 `agent.db.transaction()`。本计划不再为了不存在的 `db.lock` 去整段替换它。如果后面任务仍然贴出了一份 `_transaction`，那份代码也必须委托 `agent.db.transaction()`，不要提 `db.lock`。
2. `hold_lease` 增加可选关键字 `sleeper`。参数为空时读取 `clock.lease_sleeper`。默认 `ThreadSleeper.wait(seconds, stop)` 调用 `stop.wait(timeout=seconds)`，`stop` 被设置后立即返回，不会把一次短步骤拖成半段租约。进入 `with` 块之前先续租一次，计划 1 的租约测试仍能在块内读到 `lease_owner`。之后的循环先等待，再按当时的 `clock.now()` 续租。测试把 `ManualSleeper` 赋给 `agent.clock.lease_sleeper`：它只记录秒数并停在门闩上，`release()` 之后才继续，不按秒数阻塞。`lease_seconds < 15` 抛 `VALIDATION_ERROR`。走通成片的测试不把配置里的租约改到 15 秒以下。直接用 14 调用 `hold_lease` 只验证这道守卫。
3. 自动退避的等待秒数取 `VideoAgentError.details["retry_after_seconds"]`，缺省或非法时为 1。只有 `PROVIDER_TEMPORARY` 和 `SHOT_DURATION_SHORT` 增加 `generations.auto_attempts_used`。退避和查询 `pending` 时清掉租约，只写 `next_attempt_at`，任务保持原来的进行中状态。这样测试推进 `FrozenClock` 即可再次领取。
4. `submission_state` 为 `intended` 或 `uncertain` 时先查询，不直接再提交。查询得到 `absent` 之后，同一拍用原来的幂等键调用 `submit_shot`。在这之前不提交。`uncertain=True` 或没有外部任务号时不保存外部任务号，执行保持进行中，不增加 `auto_attempts_used`。查询成功但还没有外部任务号时，下载参数使用 `provider_idempotency_key`。`submit_shot` 抛出的 `PROVIDER_TEMPORARY` 留下 `intended`，下一拍先查询；只有供应商明确返回已创建的结果才算提交成功。
5. 已确认可以下载之后，把该执行的 `stage_detail` 写成 `download`。下一步导入先读这个值，再进入 `_enter`。下载失败时重新写回 `download`，下一次只调用 `download`。`_schedule_generation_retry` 不改 `stage_detail`。
6. 左侧邻居不在本次替换中时，用基础代该邻居片段的最后一帧作为 `first_frame_path`。右侧邻居也在替换中时不传 `tail_frame_path`。方案只有一个镜头时不提取相邻帧；该镜头仍用 `first_frame_fitted.png` 作为 `first_frame_path`。`supports_first_frame` 或 `supports_tail_frame` 为假时，对应画面改追加到 `reference_paths`。
7. `kind=shots` 时，未出现在 `generation_shots` 里的镜头从基础代复制无字幕片段，插入 `status=reused`。`_enter` 的 `total_shots` 不统计 `reused`。`_step_compose` 接受 `imported` 和 `reused`。音轨复制 `voice.m4a`、`music.m4a`、`cues.json`，不调用配音和音乐实现。
8. 任何一个镜头还没有 `external_task_id` 时，本拍开始前把 `work_items.copied_config_json` 抄到 `generations.copied_config_json`。已经有外部任务号的 `query` 和 `download` 读执行行里的这份 JSON，追加到 `agent.provider_config_calls`，不读当时的新文件，也不读 `agent.config`。

```python
def drain(agent: VideoAgent, task_id: str, limit: int = 80):
    task = agent.get_task(task_id)
    for _ in range(limit):
        if task.status not in {"pending", "planning", "generating"}:
            return task
        result = agent.tick()
        if not result.did_work:
            agent.clock.advance(1)
        task = agent.get_task(task_id)
    raise AssertionError((task.status, task.stage, task.failure))
```

```python
def rebuilds_audio(kind: str) -> bool:
    return kind == "full"


def _base_generation_dir(agent, generation: dict) -> Path | None:
    if not generation.get("base_artifact_id"):
        return None
    with _transaction(agent) as conn:
        row = _one(
            conn,
            "SELECT task_id, generation_id FROM artifacts WHERE artifact_id=?",
            (generation["base_artifact_id"],),
        )
    if row is None:
        return None
    return agent.files.home / "tasks" / row["task_id"] / "generations" / row["generation_id"]


def _copy_base_audio(agent, generation: dict, root: Path, document: PlanDocument) -> None:
    base = _base_generation_dir(agent, generation)
    if base is None:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "找不到基础成品的执行目录", stage="preparing_audio", retryable=True)
    root.mkdir(parents=True, exist_ok=True)
    for name in ("voice.m4a", "music.m4a", "cues.json"):
        source = base / name
        dest = root / name
        if source.is_file() and not dest.is_file():
            shutil.copyfile(source, dest)
    if document.voiceover and not (root / "voice.m4a").is_file():
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "基础配音不存在", stage="preparing_audio", retryable=True)
    if document.music and not (root / "music.m4a").is_file():
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "基础音乐不存在", stage="preparing_audio", retryable=True)
    if document.subtitles and document.voiceover and not (root / "cues.json").is_file():
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "基础字幕时间不存在", stage="preparing_audio", retryable=True)


def _step_audio(agent, work: dict) -> None:
    _enter(agent, work, "audio")
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    root = _gen_dir(agent, work)
    if not rebuilds_audio(str(generation["kind"])):
        _copy_base_audio(agent, generation, root, document)
        _advance(agent, work, "compose")
        return
    if not document.voiceover and not document.music:
        _advance(agent, work, "compose")
        return
    if document.voiceover and agent.voice is None and not (root / "voice.m4a").is_file():
        raise VideoAgentError(
            "PROVIDER_REJECTED",
            "配音已开启，但没有可用的配音实现",
            stage="preparing_audio",
            retryable=True,
        )
    bitrate = int(agent.config.audio_bitrate)
    if document.voiceover and not (root / "voice.m4a").is_file():
        _build_voice(agent, work, document, root, bitrate)
    if document.music and not (root / "music.m4a").is_file():
        _build_music(agent, work, document, root, bitrate)
```

```python
def _reuse_base_shots(agent, work: dict, generation: dict, document: PlanDocument) -> None:
    base = _base_generation_dir(agent, generation)
    if base is None:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "找不到基础成品的执行目录", stage="preparing_first_frame", retryable=True)
    root = _gen_dir(agent, work)
    (root / "shots").mkdir(parents=True, exist_ok=True)
    with _transaction(agent) as conn:
        existing = {
            row[0]
            for row in conn.execute(
                "SELECT shot_id FROM generation_shots WHERE generation_id=?",
                (generation["generation_id"],),
            )
        }
        for index, shot in enumerate(document.shots):
            if shot.shot_id in existing:
                conn.execute(
                    "UPDATE generation_shots SET ordinal=? WHERE generation_id=? AND shot_id=?",
                    (index, generation["generation_id"], shot.shot_id),
                )
                continue
            source = base / "shots" / f"{shot.shot_id}.mp4"
            if not source.is_file():
                raise VideoAgentError(
                    "MEDIA_EXPORT_FAILED",
                    "基础镜头片段不存在",
                    stage="preparing_first_frame",
                    retryable=True,
                    shot_ids=[shot.shot_id],
                )
            dest = root / "shots" / f"{shot.shot_id}.mp4"
            if not dest.is_file():
                shutil.copyfile(source, dest)
            relative = dest.relative_to(agent.files.home).as_posix()
            conn.execute(
                """INSERT INTO generation_shots (
                    generation_id, shot_id, ordinal, start_frame, end_frame, status, clip_path
                ) VALUES (?, ?, ?, ?, ?, 'reused', ?)""",
                (generation["generation_id"], shot.shot_id, index, shot.start_frame, shot.end_frame, relative),
            )


def _replacing_ids(generation: dict, document: PlanDocument) -> set[str]:
    if generation["kind"] == "full":
        return {shot.shot_id for shot in document.shots}
    return set(json.loads(generation["shot_ids_json"]))


def _neighbor_media(agent, work: dict, generation: dict, document: PlanDocument, shot_row: dict):
    plan_shots = list(document.shots)
    index = next(position for position, item in enumerate(plan_shots) if item.shot_id == shot_row["shot_id"])
    replacing = _replacing_ids(generation, document)
    fitted = _gen_dir(agent, work) / "first_frame_fitted.png"
    first_path = fitted if fitted.is_file() and (len(plan_shots) == 1 or index == 0) else None
    tail_path = None
    if len(plan_shots) > 1 and index > 0:
        left = plan_shots[index - 1]
        if left.shot_id in replacing:
            clip = _gen_dir(agent, work) / "shots" / f"{left.shot_id}.mp4"
        else:
            base = _base_generation_dir(agent, generation)
            clip = None if base is None else base / "shots" / f"{left.shot_id}.mp4"
        if clip is None or not clip.is_file():
            raise VideoAgentError("MEDIA_EXPORT_FAILED", "左侧相邻镜头片段不存在", stage="generating_shots", retryable=True, shot_ids=[left.shot_id])
        dest = _gen_dir(agent, work) / "frames" / f"{left.shot_id}-end.png"
        dest.parent.mkdir(parents=True, exist_ok=True)
        extract_png(clip, probe(clip).frame_count - 1, dest)
        first_path = dest
    if len(plan_shots) > 1 and index + 1 < len(plan_shots):
        right = plan_shots[index + 1]
        if right.shot_id not in replacing:
            base = _base_generation_dir(agent, generation)
            clip = None if base is None else base / "shots" / f"{right.shot_id}.mp4"
            if clip is None or not clip.is_file():
                raise VideoAgentError("MEDIA_EXPORT_FAILED", "右侧相邻镜头片段不存在", stage="generating_shots", retryable=True, shot_ids=[right.shot_id])
            dest = _gen_dir(agent, work) / "frames" / f"{right.shot_id}-start.png"
            dest.parent.mkdir(parents=True, exist_ok=True)
            extract_png(clip, 0, dest)
            tail_path = dest
    extras: list[Path] = []
    caps = agent.video.capabilities()
    if first_path is not None and not caps.supports_first_frame:
        extras.append(first_path)
        first_path = fitted if index == 0 and fitted.is_file() else None
    if tail_path is not None and not caps.supports_tail_frame:
        extras.append(tail_path)
        tail_path = None
    return first_path, tail_path, extras
```

```python
import threading
from contextlib import contextmanager
from datetime import timedelta

from video_agent.errors import VideoAgentError

MAX_AUTO_RETRIES = 2


class ThreadSleeper:
    def wait(self, seconds: float, stop: threading.Event) -> bool:
        return stop.wait(timeout=float(seconds))


class ManualSleeper:
    def __init__(self) -> None:
        self._gate = threading.Event()
        self.entered = threading.Event()
        self.renewed = threading.Event()
        self.seconds: list[float] = []

    def wait(self, seconds: float, stop: threading.Event) -> bool:
        self.seconds.append(float(seconds))
        self.entered.set()
        self._gate.wait()
        stopped = stop.is_set()
        if not stopped:
            self._gate.clear()
            self.entered.clear()
        return stopped

    def release(self) -> None:
        self._gate.set()


@contextmanager
def hold_lease(db, work_id: str, owner: str, clock, lease_seconds: int, *, sleeper=None):
    if int(lease_seconds) < 15:
        raise VideoAgentError("VALIDATION_ERROR", "租约不得低于 15 秒")
    if sleeper is None:
        sleeper = getattr(clock, "lease_sleeper", None)
    if sleeper is None:
        sleeper = ThreadSleeper()
    stop = threading.Event()
    started = threading.Event()

    def renew() -> None:
        until = (clock.now() + timedelta(seconds=int(lease_seconds))).isoformat()
        with db.transaction() as conn:
            conn.execute(
                """UPDATE work_items
                   SET lease_owner=?, lease_until=?
                   WHERE work_id=? AND (lease_owner IS NULL OR lease_owner=?)""",
                (owner, until, work_id, owner),
            )
        renewed = getattr(sleeper, "renewed", None)
        if isinstance(renewed, threading.Event):
            renewed.set()

    def loop() -> None:
        renew()
        started.set()
        while not sleeper.wait(int(lease_seconds) / 2, stop):
            renew()

    thread = threading.Thread(target=loop, name="video-agent-lease", daemon=True)
    thread.start()
    if not started.wait(timeout=5):
        stop.set()
        release = getattr(sleeper, "release", None)
        if release is not None:
            release()
        thread.join(timeout=5)
        raise VideoAgentError("PROVIDER_TEMPORARY", "租约续期线程没有启动")
    try:
        yield
    finally:
        stop.set()
        release = getattr(sleeper, "release", None)
        if release is not None:
            release()
        thread.join(timeout=5)
```

```python
def _handle_generation_error(agent, work: dict, exc: VideoAgentError) -> None:
    if exc.code in {"PROVIDER_TEMPORARY", "SHOT_DURATION_SHORT"} and _schedule_generation_retry(agent, work, exc):

def _schedule_generation_retry(agent, work: dict, exc: VideoAgentError) -> bool:
    generation = _require_generation(agent, work["generation_id"])
    used = int(generation["auto_attempts_used"])
    if used >= MAX_AUTO_RETRIES:
        return False
    delay = 1.0
    details = exc.details if isinstance(exc.details, dict) else {}
    if "retry_after_seconds" in details:
        try:
            delay = float(details["retry_after_seconds"])
        except (TypeError, ValueError):
            delay = 1.0
    if delay < 0:
        delay = 1.0
    later = (agent.clock.now() + timedelta(seconds=delay)).isoformat()
    now = agent.clock.now().isoformat()
    stage = exc.stage or _STAGE.get(str(work["step"]))
    with _transaction(agent) as conn:
        conn.execute(
            """UPDATE generations
               SET status='running', stage=?, auto_attempts_used=?, next_attempt_at=?, updated_at=?
               WHERE generation_id=?""",
            (stage, used + 1, later, now, work["generation_id"]),
        )
        conn.execute(
            """UPDATE tasks
               SET status='generating', stage=?, updated_at=?
               WHERE task_id=?""",
            (stage, now, work["task_id"]),
        )
        conn.execute(
            """UPDATE work_items
               SET done=0, lease_owner=NULL, lease_until=NULL, next_attempt_at=?
               WHERE work_id=?""",
            (later, work["work_id"]),
        )
    return True
```

```python
def _query_before_submit(agent, work: dict, shot: dict) -> str:
```
```python
    config = _provider_config(agent, work, shot)
    _remember_provider_config(agent, "query", config)
    with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
        queried = agent.video.query(
```
