# 核心包实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出可注入规划器的 `video_agent` 核心：配置、SQLite、文件库、幂等、状态写入和规划工人；确认与重生成只落执行记录和工作，不渲染成片。

**Architecture:** 状态变更只发生在一把 SQLite 写锁里的单个事务中。幂等重放先于状态判断，校验失败和状态冲突回滚且不留幂等行。规划由测试注入的 `Planner` 完成，`tick` 每次只推进一步；遇到 `kind=generation` 才延迟导入计划 2 的 `advance_generation`。

**Tech Stack:** Python 3.11+、Pydantic v2、Pillow、标准库 `sqlite3`、`pathlib`、`hashlib`、`threading`、`uuid`。测试用 `pytest`、`tmp_path` 和 `FrozenClock`。

## Global Constraints

- Python 3.11+。运行时依赖只有 `pydantic>=2` 和 `pillow>=10`。测试依赖 `pytest`。SQLite、Tkinter、哈希和路径使用标准库。
- 可执行文件是本机 PATH 上的 `ffmpeg` 和 `ffprobe`。帧率 30。成片是 H.264、yuv420p 的 MP4。有音轨时是 AAC、48 kHz、立体声。
- 默认视频码率 8_000_000 bps，默认音频码率 192_000 bps。
- 时长档默认 `[5, 10, 15, 30]`，默认选中 10。每一档是 1 到 30 的整数，含 30。档位不可重复，列表不可空，默认档必须属于档位。
- 画面比例只有 `9:16`、`16:9`、`1:1`、`4:5`、`3:4`、`4:3`、`3:2`、`2:3`。对应默认尺寸是 1080×1920、1920×1080、1080×1080、1080×1350、1080×1440、1440×1080、1620×1080、1080×1620。
- 覆盖某一档尺寸时，宽和高都是正偶数，并且 `width * ratio_h == height * ratio_w`。不能增删比例档。
- `max_images` 的允许范围是 1 到 12。`max_file_bytes` 的允许范围是 1 到 20971520。等于默认值合法，大于默认值拒绝。
- 数据目录默认是进程当前目录下的 `.video-agent/`，环境变量 `VIDEO_AGENT_HOME` 可改。配置缺失时写入默认 `config.json`。配置读不出或违反规则时抛出错误，不改写原文件。
- 密钥只放在该目录的 `config.json`。仓库忽略 `.video-agent/`。
- 租约默认 60 秒，配置值不得低于 15 秒。自动退避只追加 2 次，常量名 `MAX_AUTO_RETRIES`。
- 配音语速只允许 0.5 到 2.0 倍。仍放不进已确认区间时，错误码是 `VOICEOVER_DOES_NOT_FIT`。
- 幂等记录只在状态写入成功的同一事务里插入。校验失败和状态冲突不写幂等记录。重放检查在状态判断之前。重放返回当时存下的 `TaskView`，不新建规划或视频执行。
- 帧数分摊并列时，改镜头列表里下标最小的镜头。
- 错误码只用规格里的表：`VALIDATION_ERROR`、`NOT_FOUND`、`STATE_CONFLICT`、`PLAN_VERSION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`FIRST_FRAME_NOT_IMPLEMENTED`、`VOICEOVER_DOES_NOT_FIT`、`SHOT_DURATION_SHORT`、`ASSET_MISSING`、`PROVIDER_TEMPORARY`、`PROVIDER_REJECTED`、`PROVIDER_SUBMISSION_UNCERTAIN`、`MEDIA_EXPORT_FAILED`。不新增错误码。
- 不引入 Agent 编排框架，不实现 HTTP，不实现首帧生图，不写真实供应商报文。

每个任务的提交只使用 `git add` 和 `git commit -m`。不要修改 git 配置，不要 push。命令在仓库根目录执行。测试数据目录用 pytest 的 `tmp_path`。时间用 `FrozenClock`。本计划不调用 FFmpeg，不创建 `pipeline.py` 或 `factory.py`，也不对生成工作调用 `tick`。

## 契约决议

公开类名、方法签名、字段名、表名和错误码都不改。下面只补契约没有写出的内部名字和调用约定。

1. 文件清单没有 `video_agent/__init__.py`，但服务签名要求该模块导出 `VideoAgent` 和 `VideoAgentError`。本计划创建该文件，且只导出这两个名字。
2. `save_settings` 在校验 `mode="real"` 时延迟导入 `video_agent.factory.REAL_ADAPTERS`。`VideoAgent` 仅在五个适配器都没注入时延迟导入 `build_adapters`。导入失败时，真实适配器表视为 `{}`，适配器保持 `None`。因此本计划里切到 `real` 失败，消息包含「没有已注册的真实规划或视频适配器」。
3. 未注入 `video` 时，`PlanRequest.video_capabilities` 使用 `video_agent.ports.DEFAULT_VIDEO_CAPABILITIES`：`native_aspects=["9:16"]`，`max_segment_seconds=30`，三种参考都为真。
4. `redistribute` 的四舍五入是半远离零，用整数公式 `(2 * numerator + denominator) // (2 * denominator)`，不用 Python 内置 `round`。
5. 适配器字段名转成小写后，只要包含 `key`、`token` 或 `secret`，空字符串就保留原值。
6. `claim_next` 领取 `done=0`、`ready_at<=now`、租约为空或 `lease_until<now` 的工作，并且 `next_attempt_at` 为空或不晚于 `now`。`ready_at` 相同时按 `work_id` 升序。`recover` 只清理 `lease_until<now` 的租约。
7. 规划自动退避次数写入该工作 `copied_config_json` 的 `_auto_attempts_used`。读取适配器时忽略这个键。用尽 `MAX_AUTO_RETRIES` 后才把任务写成 `failed`。生成执行的次数仍用 `generations.auto_attempts_used`。没有 `retry_after_seconds` 时，下一次 `ready_at` 定为 1 秒后。
8. 计划 2 要实现的函数签名是 `advance_generation(agent: VideoAgent, work_id: str) -> str`。返回值是本步名称。计划 1 只在已领取工作的 `kind=="generation"` 分支里导入它。
9. 内部函数供计划 2 按这个顺序调用：先 `record_artifact`，再 `mark_generation_succeeded` 或 `mark_generation_failed`。另外还有 `publish_document`、`apply_patch`、`start_generation`、`snapshot_config`、`assert_mutation_allowed`、`read_task_view`。它们不是 `VideoAgent` 的新公开方法。
10. `kind="full"` 的执行把方案镜头按 `start_frame` 顺序写入 `shot_ids_json` 和 `generation_shots`。调用方不用传镜头标识。`kind="shots"` 只为请求里的镜头插入 `generation_shots`，即使这些镜头覆盖了整条方案，`kind` 仍是 `shots`。
11. `retry_generation` 不新建执行。失败阶段映射为：`queued` 和 `preparing_first_frame` → `first_frame`；`generating_shots` → `submit_shot`；`preparing_audio` → `audio`；`composing` → `compose`；`checking_visuals` → `visual`；`exporting` → `export`。调用方重试时把该执行的 `auto_attempts_used` 置 0。尚无 `external_task_id` 时按当时配置重抄 `copied_config_json`；已有外部任务号则保留原配置。镜头已提交未导入的更细续跑由计划 4 收紧。
12. `list_tasks` 按 `updated_at` 降序，相同时按 `task_id` 降序。`list_artifacts` 按 `version` 降序。
13. `register_asset` 的 `filename` 只保留基名。`path` 与 `data` 必须恰好提供一个。文件写入成功后才插入 `assets` 并返回同一个 `asset_id`。
14. `InputPatch.video_options` 和 `audio_options` 一旦传入就整体覆盖。`video_options.duration_seconds is None` 时改用当前配置的默认档。`images is None` 表示不改图片。
15. `RegenerateRequest` 没有时长、布局、场景或文案字段。局部请求的 `VALIDATION_ERROR` 只覆盖基础成品不存在、不属于本任务、镜头标识为空或不属于该成品。本计划不另造请求字段。
16. 配音语速 0.5 到 2.0 以及 `VOICEOVER_DOES_NOT_FIT` 的判定由成片链路实现。本计划只让 `VideoAgentError` 能携带该错误码，并在 `retryable=false` 时拒绝 `retry_generation`。
17. 放弃草稿时，若已确认版本没有任何视频执行，任务状态写成 `succeeded`，`generation_id` 为空。确认流程在同一事务里总会插入执行，所以正常调用到不了这里。
18. `VideoAgent` 持有属性 `home`、`clock`、`db`、`files`、`planner`、`video`、`voice`、`music`、`visual`、`worker_owner`，供同进程的后续计划使用，不新增公开方法。
19. `TaskView` 额外带回 `product_info`、`user_prompt`、`video_options`、`audio_options`、`image_asset_ids` 和 `first_frame_asset_id`。`product_name` 与 `product_info.name` 相同。`task_row_to_view` 从任务行填入这些字段。

```python
from datetime import datetime, timedelta, timezone
from typing import Protocol


class Clock(Protocol):
    def now(self) -> datetime: ...


class SystemClock:
    def now(self) -> datetime:
        return datetime.now(timezone.utc)


class FrozenClock:
    def __init__(self, start: datetime) -> None:
        if start.tzinfo is None or start.utcoffset() is None:
            raise ValueError("start must be timezone-aware")
        self._now = start

    def now(self) -> datetime:
        return self._now

    def advance(self, seconds: float) -> None:
        self._now = self._now + timedelta(seconds=seconds)
```

```python
def _fail(message: str) -> None:
    raise VideoAgentError("VALIDATION_ERROR", message)


def _plain_int(value: object, label: str) -> int:
    if isinstance(value, bool) or not isinstance(value, int):
        _fail(f"{label} 必须是整数")
    return int(value)


def _is_secret(name: str) -> bool:
    lowered = name.lower()
    return "key" in lowered or "token" in lowered or "secret" in lowered


def _validate_data(data: object) -> AppConfig:
    if not isinstance(data, dict):
        _fail("配置必须是 JSON 对象")
    mode = data.get("mode")
    if mode not in ("fake", "real"):
        _fail("模式只能是 fake 或 real")
    raw_tiers = data.get("duration_tiers")
    if not isinstance(raw_tiers, list) or len(raw_tiers) == 0:
        _fail("时长档不能为空")
    tiers: list[int] = []
    for item in raw_tiers:
        number = _plain_int(item, "时长档")
        if number < 1 or number > 30:
            _fail("时长档必须是 1 到 30 的整数")
        tiers.append(number)
    if len(set(tiers)) != len(tiers):
        _fail("时长档不能重复")
    default_duration = _plain_int(data.get("default_duration"), "默认时长")
    if default_duration not in tiers:
        _fail("默认时长必须属于时长档")
    max_images = _plain_int(data.get("max_images"), "图片张数上限")
    if max_images < 1 or max_images > 12:
        _fail("图片张数上限必须在 1 到 12 之间")
    max_file_bytes = _plain_int(data.get("max_file_bytes"), "单文件上限")
    if max_file_bytes < 1 or max_file_bytes > 20971520:
        _fail("单文件上限必须在 1 到 20971520 之间")
    video_bitrate = _plain_int(data.get("video_bitrate"), "视频码率")
    audio_bitrate = _plain_int(data.get("audio_bitrate"), "音频码率")
    if video_bitrate < 1 or audio_bitrate < 1:
        _fail("码率必须是正整数")
    lease_seconds = _plain_int(data.get("lease_seconds"), "租约秒数")
    if lease_seconds < 15:
        _fail("租约不得低于 15 秒")
    raw_resolutions = data.get("resolutions")
    if not isinstance(raw_resolutions, dict) or set(raw_resolutions) != set(ASPECT_RATIOS):
        _fail("不能增删比例档")
    resolutions: dict[str, tuple[int, int]] = {}
    for ratio in ASPECT_RATIOS:
        pair = raw_resolutions[ratio]
        if not isinstance(pair, (list, tuple)) or len(pair) != 2:
            _fail("分辨率必须是宽和高")
        width = _plain_int(pair[0], "宽度")
        height = _plain_int(pair[1], "高度")
        ratio_w, ratio_h = RATIO_PAIRS[ratio]
        if width <= 0 or height <= 0 or width % 2 != 0 or height % 2 != 0:
            _fail("覆盖尺寸时宽和高都必须是正偶数，并且比例不变")
        if width * ratio_h != height * ratio_w:
            _fail("覆盖尺寸时宽和高都必须是正偶数，并且比例不变")
        resolutions[ratio] = (width, height)
    raw_adapters = data.get("adapters")
    if not isinstance(raw_adapters, dict) or set(raw_adapters) != set(ADAPTER_ROLES):
        _fail("适配器必须包含规划、视频、配音、音乐和视觉检查")
    adapters: dict[str, AdapterConfig] = {}
    for role in ADAPTER_ROLES:
        entry = raw_adapters[role]
        if not isinstance(entry, dict) or not isinstance(entry.get("adapter"), str) or entry.get("adapter") == "":
            _fail("适配器名称不能为空")
        adapters[role] = AdapterConfig.model_validate(entry)

        audio_bitrate=audio_bitrate,
        lease_seconds=lease_seconds,
        resolutions=resolutions,
        adapters=adapters,

def load_config(home: Path) -> AppConfig:
    home.mkdir(parents=True, exist_ok=True)
    path = home / "config.json"
    if not path.exists():
        path.write_text(DEFAULT_CONFIG_JSON, encoding="utf-8")
        return _validate_data(json.loads(DEFAULT_CONFIG_JSON))
    raw = path.read_bytes()
    try:
        data = json.loads(raw.decode("utf-8"))
        return _validate_data(data)
    except VideoAgentError:
        raise
    except (UnicodeError, json.JSONDecodeError, TypeError, ValueError) as exc:
        raise VideoAgentError("VALIDATION_ERROR", "配置无法读取或不符合规则") from exc


def _load_real_adapters() -> dict:
    try:
        from video_agent.factory import REAL_ADAPTERS
    except ImportError:
        return {}
    if not isinstance(REAL_ADAPTERS, dict):
        return {}
    return dict(REAL_ADAPTERS)


def _assert_real_mode(adapters: dict[str, AdapterConfig]) -> None:
    registry = _load_real_adapters()
    missing: list[str] = []
    for role in ("planner", "video"):
        name = adapters[role].adapter
        if name in {"fake", "none"} or name not in registry:
            missing.append(role)
            continue
        entry = registry.get(name)
        required: list[str] = []
        if isinstance(entry, dict):
            raw_required = entry.get("required", [])
            if isinstance(raw_required, list):
                required = [str(item) for item in raw_required]
        fields = adapters[role].field_map()
        for field in required:
            if fields.get(field, "") == "":
                missing.append(f"{role}.{field}")
    if missing:
        raise VideoAgentError(
            "VALIDATION_ERROR",
            "没有已注册的真实规划或视频适配器",
            details={"missing": missing},
        )
    for role in ("voice", "music", "visual"):
        name = adapters[role].adapter
        if name not in {"fake", "none"} and name not in registry:
            raise VideoAgentError("VALIDATION_ERROR", f"{role} 适配器未注册")


def _merge_adapter(current: AdapterConfig, patch: AdapterSetting) -> AdapterConfig:
    merged = current.field_map()
    for key, value in patch.fields.items():
        if _is_secret(key) and value == "":
            continue
        merged[key] = value
    body: dict[str, object] = {"adapter": patch.adapter}
    body.update(merged)
    return AdapterConfig.model_validate(body)


def save_settings(home: Path, patch: SettingsPatch) -> AppConfig:
    path = home / "config.json"
    current = load_config(home)
    before = path.read_bytes()
    data = config_to_dict(current)
    if patch.duration_tiers is not None:
        data["duration_tiers"] = list(patch.duration_tiers)
    if patch.default_duration is not None:
        data["default_duration"] = patch.default_duration
    if patch.mode is not None:
        data["mode"] = patch.mode
    adapters = {role: current.adapters[role] for role in ADAPTER_ROLES}
    for role in ADAPTER_ROLES:
        role_patch = getattr(patch, role)
        if role_patch is not None:
            adapters[role] = _merge_adapter(adapters[role], role_patch)
    data["adapters"] = {role: _adapter_body(adapters[role]) for role in ADAPTER_ROLES}
    try:
        updated = _validate_data(data)
        if updated.mode == "real":
            _assert_real_mode(updated.adapters)
    except VideoAgentError:
        if path.exists() and path.read_bytes() != before:
            path.write_bytes(before)
        raise
    path.write_text(_dump(updated), encoding="utf-8")
    return updated
```

```python
from video_agent.errors import VideoAgentError


def _round_half_away(numerator: int, denominator: int) -> int:
    return (2 * numerator + denominator) // (2 * denominator)


def _longest_index(values: list[int], minimum: int) -> int | None:
    best_at: int | None = None
    best_value: int | None = None
    for index, value in enumerate(values):
        if value < minimum:
            continue
        if best_value is None or value > best_value:
            best_value = value
            best_at = index
    return best_at


def redistribute(lengths: list[int], new_total: int) -> list[int]:
    if new_total < 1 or any(length < 1 for length in lengths):
        raise VideoAgentError("VALIDATION_ERROR", "帧数必须是正整数")
    if len(lengths) > new_total:
        raise VideoAgentError("VALIDATION_ERROR", "镜头数大于总帧数")
    if len(lengths) == 0:
        raise VideoAgentError("VALIDATION_ERROR", "没有镜头可分摊")
    old_total = sum(lengths)
    assigned = [max(1, _round_half_away(length * new_total, old_total)) for length in lengths]
    guard = new_total + len(lengths)
    while sum(assigned) > new_total:
        guard -= 1
        index = _longest_index(assigned, 2)
        if guard < 0 or index is None:
            raise VideoAgentError("VALIDATION_ERROR", "无法在每镜至少 1 帧的前提下扣平")
        assigned[index] -= 1
    while sum(assigned) < new_total:
        index = _longest_index(assigned, 1)
        if index is None:
            raise VideoAgentError("VALIDATION_ERROR", "无法在每镜至少 1 帧的前提下扣平")
        assigned[index] += 1
    return assigned
```

```python
import io
import uuid
from dataclasses import dataclass
from pathlib import Path
from typing import Literal

from PIL import Image, UnidentifiedImageError

from video_agent.errors import VideoAgentError


@dataclass(frozen=True)
class StoredAsset:
    asset_id: str
    kind: str
    filename: str
    media_type: str
    byte_size: int
    relative_path: str


class LocalFileStore:
    def __init__(self, home: Path) -> None:
        self.home = home

    def path_for(self, relative_path: str) -> Path:
        root = self.home.resolve()
        target = (self.home / relative_path).resolve()
        if not target.is_relative_to(root):
            raise VideoAgentError("VALIDATION_ERROR", "文件路径越界")
        return target

    def exists(self, relative_path: str) -> bool:
        return self.path_for(relative_path).is_file()

    def read_bytes(self, relative_path: str) -> bytes:
        return self.path_for(relative_path).read_bytes()

    def write_bytes(self, relative_path: str, data: bytes) -> Path:
        target = self.path_for(relative_path)
        target.parent.mkdir(parents=True, exist_ok=True)
        temporary = target.with_name(target.name + ".partial")
        temporary.write_bytes(data)
        temporary.replace(target)
        return target

    def register(
        self,
        *,
        filename: str,
        kind: Literal["image", "audio"],
        data: bytes,
        max_bytes: int,
    ) -> StoredAsset:
        if kind not in ("image", "audio"):
            raise VideoAgentError("VALIDATION_ERROR", "种类只能是 image 或 audio", fields=["kind"])
        name = Path(filename).name
        if name in {"", ".", ".."}:
            raise VideoAgentError("VALIDATION_ERROR", "文件名不能为空", fields=["filename"])
        if len(data) < 1 or len(data) > max_bytes:
            raise VideoAgentError("VALIDATION_ERROR", "文件超过大小限制或为空", fields=["data"])
        media_type = _media_type(kind, data)
        asset_id = str(uuid.uuid4())
        relative_path = f"assets/{asset_id}/{name}"
        self.write_bytes(relative_path, data)
        return StoredAsset(
            asset_id=asset_id,
            kind=kind,
            filename=name,
            media_type=media_type,
            byte_size=len(data),
            relative_path=relative_path,
        )


def _media_type(kind: str, data: bytes) -> str:
    image_type = _image_type(data)
    audio_type = _audio_type(data)
    if kind == "image":
        if image_type is None:
            raise VideoAgentError("VALIDATION_ERROR", "图片只接受 JPEG、PNG 或 WebP", fields=["data"])
        try:
            with Image.open(io.BytesIO(data)) as image:
                image.load()
        except (UnidentifiedImageError, OSError, ValueError) as exc:
            raise VideoAgentError("VALIDATION_ERROR", "图片无法解码", fields=["data"]) from exc
        return image_type
    if audio_type is None:
        raise VideoAgentError("VALIDATION_ERROR", "音频只接受 MP3、WAV 或 M4A", fields=["data"])
    return audio_type


def _image_type(data: bytes) -> str | None:
    if data.startswith(b"\xff\xd8\xff"):
        return "image/jpeg"
    if data.startswith(b"\x89PNG\r\n\x1a\n"):
        return "image/png"
    if len(data) >= 12 and data[:4] == b"RIFF" and data[8:12] == b"WEBP":
        return "image/webp"
    return None


def _audio_type(data: bytes) -> str | None:
    if len(data) >= 12 and data[:4] == b"RIFF" and data[8:12] == b"WAVE":
        return "audio/wav"
    if data.startswith(b"ID3") and len(data) >= 10:
        return "audio/mpeg"
    if len(data) >= 2 and data[0] == 0xFF and data[1] & 0xE0 == 0xE0:
        return "audio/mpeg"
    if len(data) >= 12 and data[4:8] == b"ftyp" and data[8:12] in {b"M4A ", b"isom", b"iso2", b"mp41", b"mp42", b"M4B "}:
        return "audio/mp4"
    return None
```

```python
  method TEXT NOT NULL,
  idempotency_key TEXT NOT NULL,
  request_hash TEXT NOT NULL,
  task_id TEXT,
  response_json TEXT NOT NULL,
  created_at TEXT NOT NULL,
  PRIMARY KEY (method, idempotency_key)
);
"""


class Database:
    def __init__(self, home: Path) -> None:
        home.mkdir(parents=True, exist_ok=True)
        self.path = home / "agent.sqlite"
        self._lock = threading.Lock()
        self._conn = sqlite3.connect(self.path, check_same_thread=False, isolation_level=None)
        self._conn.row_factory = sqlite3.Row
        self._conn.executescript(SCHEMA)

    @contextmanager
    def transaction(self) -> Iterator[sqlite3.Connection]:
        self._lock.acquire()
        try:
            self._conn.execute("BEGIN IMMEDIATE")
            try:
                yield self._conn
                self._conn.execute("COMMIT")
            except Exception:
                self._conn.execute("ROLLBACK")
                raise
        finally:
            self._lock.release()
```

```python
    conn: sqlite3.Connection,
    method: str,
    key: str | None,
    payload: dict,
) -> TaskView | None:
    if key is None:
        return None

        return None

    method: str,

        return

           (method, idempotency_key, request_hash, task_id, response_json, created_at)
```

```python
from video_agent.errors import VideoAgentError
```

```python
def dumps(value: object) -> str:
    return json.dumps(value, ensure_ascii=False)


def has_plan(conn: sqlite3.Connection, task_id: str) -> bool:
    row = conn.execute("SELECT 1 AS ok FROM plan_versions WHERE task_id=? LIMIT 1", (task_id,)).fetchone()
    return row is not None


def assert_mutation_allowed(task: sqlite3.Row, method: str, *, has_plan: bool) -> None:
    status = task["status"]
    scope = task["failure_scope"]
    confirmed = task["confirmed_plan_version"] is not None
    head = task["head_plan_version"]
    head_unconfirmed = head is not None and head != task["confirmed_plan_version"]
    task_id = task["task_id"]

    def deny() -> None:
        raise VideoAgentError("STATE_CONFLICT", "当前状态不允许该操作", task_id=task_id)

    if method in {"regenerate", "discard_revision"} and not confirmed:
        deny()
    if status in {"pending", "planning", "generating"}:
        deny()
    if status == "awaiting_input":
        if method == "submit_inputs" or (method == "discard_revision" and confirmed):
            return
        deny()
    if status == "awaiting_confirmation":
        if method in {"revise_plan", "confirm"}:
            return
        if method in {"regenerate", "discard_revision"} and confirmed:
            return
        deny()
    if status == "succeeded":
        if method in {"revise_plan", "regenerate"}:
            return
        deny()
    if status == "failed" and scope == "planning":
        if method == "retry_planning":
            return
        if method == "submit_inputs" and not has_plan:
            return
        if method == "revise_plan" and head is not None:
            return
        if method == "discard_revision" and confirmed:
            return
        deny()
    if status == "failed" and scope == "generation":
        if method in {"retry_generation", "regenerate", "revise_plan"}:
            return
        if method in {"confirm", "discard_revision"} and head_unconfirmed:
            return
        deny()
    deny()


def task_row_to_view(row: sqlite3.Row) -> TaskView:
    status = row["status"]
    stage = row["stage"] if status in {"planning", "generating", "failed"} else None
    failure = None
    failure_scope = None
    if status == "failed":
        failure_scope = row["failure_scope"]
        if row["failure_code"]:
            failure = FailureView(
                code=row["failure_code"],
                message=row["failure_message"] or "",
                stage=row["failure_stage"],
                retryable=bool(row["failure_retryable"]),
            )
    product = json.loads(row["product_info_json"])
    return TaskView(
        task_id=row["task_id"],
        status=status,
        stage=stage,
        stage_detail=row["stage_detail"] if stage is not None else None,
        failure_scope=failure_scope,
        failure=failure,
        questions=json.loads(row["questions_json"]) if status == "awaiting_input" else [],
        external_user_id=row["external_user_id"],
        external_request_id=row["external_request_id"],
        head_plan_version=row["head_plan_version"],
        confirmed_plan_version=row["confirmed_plan_version"],
        generation_id=row["generation_id"],
        completed_shots=row["completed_shots"] if status == "generating" else None,
        total_shots=row["total_shots"] if status == "generating" else None,
        product_name=product.get("name"),
        product_info=ProductInfo.model_validate(product),
        user_prompt=row["user_prompt"],
        video_options=VideoOptions.model_validate_json(row["video_options_json"]),
        audio_options=AudioOptions.model_validate_json(row["audio_options_json"]),
        image_asset_ids=json.loads(row["image_asset_ids_json"]),
        first_frame_asset_id=row["first_frame_asset_id"],
        updated_at=row["updated_at"],
    )


def read_task_row(conn: sqlite3.Connection, task_id: str) -> sqlite3.Row:
    row = conn.execute("SELECT * FROM tasks WHERE task_id=?", (task_id,)).fetchone()
    if row is None:
        raise VideoAgentError("NOT_FOUND", "任务不存在", task_id=task_id)
    return row


def read_task_view(conn: sqlite3.Connection, task_id: str) -> TaskView:
    return task_row_to_view(read_task_row(conn, task_id))


def insert_work(
    conn: sqlite3.Connection,
    *,
    task_id: str,
    kind: str,
    generation_id: str | None,
    ready_at: str,
    copied_config: dict,
    step: str,
) -> str:
    work_id = str(uuid.uuid4())
    conn.execute(
        """INSERT INTO work_items (
            work_id, task_id, kind, generation_id, ready_at, lease_owner, lease_until,
            copied_config_json, step, next_attempt_at, done
        ) VALUES (?, ?, ?, ?, ?, NULL, NULL, ?, ?, NULL, 0)""",
        (work_id, task_id, kind, generation_id, ready_at, dumps(copied_config), step),
    )
    return work_id
```

```python
def _blank_to_none(value: str | None) -> str | None:
    if value is None or value == "":
        return None
    return value


def _basis(product, user_prompt, images, first, video, audio) -> dict:
    return {
        "product_info": product.model_dump(mode="json"),
        "user_prompt": user_prompt,
        "images": images,
        "first_frame_asset_id": first,
        "video_options": video.model_dump(mode="json"),
        "audio_options": audio.model_dump(mode="json"),
    }


def _require_images(conn, images: list[str], max_images: int) -> None:
    if len(images) > max_images:
        raise VideoAgentError("VALIDATION_ERROR", "图片数量超过上限", fields=["images"])
    if len(set(images)) != len(images):
        raise VideoAgentError("VALIDATION_ERROR", "图片标识重复", fields=["images"])
    for asset_id in images:
        row = conn.execute("SELECT kind FROM assets WHERE asset_id=?", (asset_id,)).fetchone()
        if row is None or row["kind"] != "image":
            raise VideoAgentError("VALIDATION_ERROR", "图片素材不存在或不是图片", fields=["images"])


def _require_audio(conn, asset_id: str | None) -> None:
    asset_id = _blank_to_none(asset_id)
    if asset_id is None:
        return
    row = conn.execute("SELECT kind FROM assets WHERE asset_id=?", (asset_id,)).fetchone()
    if row is None or row["kind"] != "audio":
        raise VideoAgentError("VALIDATION_ERROR", "音乐素材不存在或不是音频", fields=["music_asset_id"])


def _require_aspect(ratio: str) -> None:
    if ratio not in ASPECT_RATIOS:
        raise VideoAgentError(
            "VALIDATION_ERROR",
            "画面比例不在预设中",
            fields=["aspect_ratio"],
            details={"aspect_ratios": list(ASPECT_RATIOS)},
        )


def _resolve_duration(value: int | None, config: AppConfig) -> int:
    if value is None:
        return config.default_duration
    if value not in config.duration_tiers:
        raise VideoAgentError(
            "VALIDATION_ERROR",
            "时长不在当前档位",
            fields=["duration_seconds"],
            details={"duration_tiers": list(config.duration_tiers)},
        )
    return value


def _check_first_frame(first: str | None, images: list[str]) -> str | None:
    if first is None:
        return None
    if first not in images:
        raise VideoAgentError("VALIDATION_ERROR", "首帧必须是本次图片中的一张", fields=["first_frame_asset_id"])
    return first
```

```python
def load_plan_document(conn: sqlite3.Connection, task_id: str, plan_version: int) -> PlanDocument:
    row = conn.execute(
        "SELECT document_json FROM plan_versions WHERE task_id=? AND plan_version=?",
        (task_id, plan_version),
    ).fetchone()
    if row is None:
        raise VideoAgentError("NOT_FOUND", "方案不存在", task_id=task_id, plan_version=plan_version)
    return PlanDocument.model_validate_json(row["document_json"])


def publish_document(conn: sqlite3.Connection, *, task_id: str, document: PlanDocument, now: str) -> int:
    row = conn.execute(
        "SELECT COALESCE(MAX(plan_version), 0) + 1 AS n FROM plan_versions WHERE task_id=?",
        (task_id,),
    ).fetchone()
    version = int(row["n"])
    conn.execute(
        """INSERT INTO plan_versions (task_id, plan_version, document_json, abandoned, created_at)
           VALUES (?, ?, ?, 0, ?)""",
        (task_id, version, document.model_dump_json(), now),
    )
    conn.execute(
        """UPDATE tasks SET
            status='awaiting_confirmation', stage=NULL, stage_detail=NULL,
            failure_scope=NULL, failure_code=NULL, failure_message=NULL,
            failure_stage=NULL, failure_retryable=NULL, failure_details_json=NULL,
            questions_json='[]', head_plan_version=?, pending_instruction=NULL,
            completed_shots=NULL, total_shots=NULL, updated_at=?
           WHERE task_id=?""",
        (version, now, task_id),
    )
    return version


def validate_frame_span(shots: list[ShotPlan], total_frames: int) -> None:
    if len(shots) == 0:
        raise VideoAgentError("VALIDATION_ERROR", "方案至少要有一个镜头", fields=["shots"])
    cursor = 0
    for shot in shots:
        if shot.start_frame != cursor or shot.end_frame <= shot.start_frame:
            raise VideoAgentError("VALIDATION_ERROR", "帧区间必须首尾相接", fields=["shots"])
        cursor = shot.end_frame
    if cursor != total_frames:
        raise VideoAgentError("VALIDATION_ERROR", "帧区间必须覆盖整段时长", fields=["shots"])


def apply_patch(
    document: PlanDocument,
    patch: PlanPatch,
    *,
    duration_tiers: list[int],
    native_aspects: list[str],
    image_asset_ids: list[str],
    audio_asset_ids: set[str],
) -> PlanDocument:
    if patch.shots is not None and patch.shot_texts is not None:
        raise VideoAgentError("VALIDATION_ERROR", "shots 和 shot_texts 不能同时出现", fields=["shots", "shot_texts"])
    if patch.clear_first_frame and patch.first_frame_asset_id:
        raise VideoAgentError("VALIDATION_ERROR", "不能同时指定和清除首帧", fields=["first_frame_asset_id"])
    if patch.clear_music_asset and patch.music_asset_id:
        raise VideoAgentError("VALIDATION_ERROR", "不能同时指定和清除音乐素材", fields=["music_asset_id"])
    duration = document.duration_seconds
    if patch.duration_seconds is not None:
        if patch.duration_seconds not in duration_tiers:
            raise VideoAgentError(
                "VALIDATION_ERROR",
                "时长不在当前档位",
                fields=["duration_seconds"],
                details={"duration_tiers": list(duration_tiers)},
            )
        duration = patch.duration_seconds
    aspect = document.aspect_ratio
    fit = document.fit
    if patch.aspect_ratio is not None:
        if patch.aspect_ratio not in ASPECT_RATIOS:
            raise VideoAgentError(
                "VALIDATION_ERROR",
                "画面比例不在预设中",
                fields=["aspect_ratio"],
                details={"aspect_ratios": list(ASPECT_RATIOS)},
            )
        aspect = patch.aspect_ratio
        if patch.fit is not None:
            fit = patch.fit
        elif aspect in native_aspects:
            fit = "native"
        else:
            fit = "pad"
    elif patch.fit is not None:
        fit = patch.fit
    subtitles = document.subtitles if patch.subtitles is None else patch.subtitles
    voiceover = document.voiceover if patch.voiceover is None else patch.voiceover
    music = document.music if patch.music is None else patch.music
    language = document.language if patch.language is None else patch.language
    voice_preference = document.voice_preference if patch.voice_preference is None else patch.voice_preference
    music_direction = document.music_direction if patch.music_direction is None else patch.music_direction
    music_asset_id = None if patch.clear_music_asset else document.music_asset_id
    if patch.music_asset_id is not None:
        if patch.music_asset_id not in audio_asset_ids:
            raise VideoAgentError("VALIDATION_ERROR", "音乐素材不存在或不是音频", fields=["music_asset_id"])
        music_asset_id = patch.music_asset_id
    shared = document.shared_visual if patch.shared_visual is None else patch.shared_visual
    first_source = document.first_frame_source
    first_id = document.first_frame_asset_id
    if patch.clear_first_frame:
        first_source = "generate"
        first_id = None
    elif patch.first_frame_asset_id is not None:
        if patch.first_frame_asset_id not in image_asset_ids:
            raise VideoAgentError("VALIDATION_ERROR", "首帧必须是本任务图片中的一张", fields=["first_frame_asset_id"])
        first_source = "selected"
        first_id = patch.first_frame_asset_id
    if patch.shots is not None:
        shots = [shot.model_copy(deep=True) for shot in patch.shots]
    else:
        shots = [shot.model_copy(deep=True) for shot in document.shots]
        if patch.shot_texts:
            index_by_id = {shot.shot_id: index for index, shot in enumerate(shots)}
            for text in patch.shot_texts:
                index = index_by_id.get(text.shot_id)
                if index is None:
                    raise VideoAgentError("VALIDATION_ERROR", "镜头标识不存在", fields=["shot_texts"], shot_ids=[text.shot_id])
                updates = {}
                for field in ("content", "action", "shot_size", "camera", "scene_id", "subtitle_text", "voiceover_text"):
                    value = getattr(text, field)
                    if value is not None:
                        updates[field] = value
                shots[index] = shots[index].model_copy(update=updates)
        if duration != document.duration_seconds:
            lengths = [shot.end_frame - shot.start_frame for shot in shots]
            resized = []
            cursor = 0
            for shot, length in zip(shots, redistribute(lengths, duration * 30), strict=True):
                resized.append(shot.model_copy(update={"start_frame": cursor, "end_frame": cursor + length}))
                cursor += length
            shots = resized
    validate_frame_span(shots, duration * 30)
    if subtitles and not document.subtitles and any(shot.subtitle_text.strip() == "" for shot in shots):
        raise VideoAgentError("VALIDATION_ERROR", "打开字幕时每个镜头都要有字幕文案", fields=["subtitles"])
    if voiceover and not document.voiceover and any(shot.voiceover_text.strip() == "" for shot in shots):
        raise VideoAgentError("VALIDATION_ERROR", "打开配音时每个镜头都要有配音文案", fields=["voiceover"])
    if music and not document.music and music_direction.strip() == "" and not music_asset_id:
        raise VideoAgentError("VALIDATION_ERROR", "打开音乐时要有音乐方向或已登记音频", fields=["music"])
    return document.model_copy(
        update={
            "shared_visual": shared,
            "shots": shots,
            "music_direction": music_direction,
            "music_asset_id": music_asset_id,
            "duration_seconds": duration,
            "aspect_ratio": aspect,
            "fit": fit,
            "subtitles": subtitles,
            "voiceover": voiceover,
            "music": music,
            "first_frame_source": first_source,
            "first_frame_asset_id": first_id,
            "language": language,
            "voice_preference": voice_preference,
        }
    )
```

```python
        raise VideoAgentError("NOT_FOUND", "执行不存在", generation_id=generation_id)
    conn.execute(
        """UPDATE generations SET
            status='succeeded', failure_code=NULL, failure_message=NULL,
            failure_stage=NULL, failure_retryable=NULL, failure_details_json=NULL, updated_at=?
           WHERE generation_id=?""",
        (now, generation_id),
    )
    task = read_task_row(conn, generation["task_id"])

           WHERE task_id=?""",
        (status, now, generation["task_id"]),
    )
```

```python
import threading
from contextlib import contextmanager
from datetime import timedelta

from video_agent.errors import VideoAgentError

MAX_AUTO_RETRIES = 2


@contextmanager
def hold_lease(db, work_id: str, owner: str, clock, lease_seconds: int):
    stop = threading.Event()
    started = threading.Event()

    def renew() -> None:
        until = (clock.now() + timedelta(seconds=lease_seconds)).isoformat()
        with db.transaction() as conn:
            conn.execute(
                "UPDATE work_items SET lease_owner=?, lease_until=? WHERE work_id=?",
                (owner, until, work_id),
            )

    def loop() -> None:
        renew()
        started.set()
        while not stop.wait(lease_seconds / 2):
            renew()

    thread = threading.Thread(target=loop, name="video-agent-lease", daemon=True)
    thread.start()
    if not started.wait(timeout=5):
        stop.set()
        raise VideoAgentError("PROVIDER_TEMPORARY", "租约续期线程没有启动")
    try:
        yield
    finally:
        stop.set()
        thread.join(timeout=5)
```

```python
def tick_once(agent) -> TickResult:
    config = load_config(agent.home)
    now = agent.clock.now()
    now_iso = now.isoformat()
    lease_until = (now + timedelta(seconds=config.lease_seconds)).isoformat()
    with agent.db.transaction() as conn:
        work = _claim(conn, owner=agent.worker_owner, now_iso=now_iso, lease_until=lease_until)
        if work is None:
            return TickResult(did_work=False)
        if work["kind"] == "planning" and work["step"] == "start":
            conn.execute(
                "UPDATE tasks SET status='planning', stage='planning', stage_detail=NULL, updated_at=? WHERE task_id=?",
                (now_iso, work["task_id"]),
            )
            conn.execute(
                "UPDATE work_items SET step='finish', lease_owner=NULL, lease_until=NULL WHERE work_id=?",
                (work["work_id"],),
            )
            return TickResult(did_work=True, task_id=work["task_id"], step="start")
        if work["kind"] == "planning" and work["step"] == "finish":
            work_id = work["work_id"]
            task_id = work["task_id"]
            mode = "finish"
        elif work["kind"] == "generation":
            work_id = work["work_id"]
            task_id = work["task_id"]
            mode = "generation"
        else:
            raise VideoAgentError("STATE_CONFLICT", "未知的工作步骤", task_id=work["task_id"])
    if mode == "generation":
        from video_agent.pipeline import advance_generation

        step = advance_generation(agent, work_id)
        return TickResult(did_work=True, task_id=task_id, step=step)
    _finish_planning(agent, work_id)
    return TickResult(did_work=True, task_id=task_id, step="finish")


def _claim(conn, *, owner: str, now_iso: str, lease_until: str):
    row = conn.execute(
        """SELECT * FROM work_items
           WHERE done=0 AND ready_at<=?
             AND (next_attempt_at IS NULL OR next_attempt_at<=?)
             AND (lease_until IS NULL OR lease_until<?)
           ORDER BY ready_at ASC, work_id ASC
           LIMIT 1""",
        (now_iso, now_iso, now_iso),
    ).fetchone()

        return None
    conn.execute(
        "UPDATE work_items SET lease_owner=?, lease_until=? WHERE work_id=?",
        (owner, lease_until, row["work_id"]),

    config = load_config(agent.home)
    now = agent.clock.now().isoformat()
    with agent.db.transaction() as conn:

            return
        questions = _nonempty(getattr(outcome, "questions", None))

                    status='awaiting_input', stage=NULL, stage_detail=NULL,
                    failure_scope=NULL, failure_code=NULL, failure_message=NULL,
                    failure_stage=NULL, failure_retryable=NULL, failure_details_json=NULL,

                   WHERE task_id=?""",
                (dumps(questions), now, task["task_id"]),
            )
            _finish_work(conn, work_id)
            return
        document = getattr(outcome, "document", None)
        patch = getattr(outcome, "patch", None)
        if patch is not None:

def _schedule_retry(conn, agent, work, error: VideoAgentError) -> bool:
    copied = json.loads(work["copied_config_json"])
    used = int(copied.get("_auto_attempts_used", 0))
    if used >= MAX_AUTO_RETRIES:
        return False
    copied["_auto_attempts_used"] = used + 1
    delay = 1.0
    if isinstance(error.details, dict) and "retry_after_seconds" in error.details:
        delay = float(error.details["retry_after_seconds"])
    if delay < 0:
        delay = 0.0
    nxt = (agent.clock.now() + timedelta(seconds=delay)).isoformat()
    conn.execute(
        """UPDATE work_items SET
            copied_config_json=?, next_attempt_at=?, ready_at=?,
            lease_owner=NULL, lease_until=NULL, done=0, step='finish'
           WHERE work_id=?""",
        (dumps(copied), nxt, nxt, work["work_id"]),
    )
    return True


def _validate_planner_document(conn, task, document: PlanDocument) -> None:
    video = VideoOptions.model_validate_json(task["video_options_json"])
    if document.duration_seconds != video.duration_seconds:
        raise VideoAgentError("PROVIDER_REJECTED", "方案秒数不是已选档位")
    validate_frame_span(document.shots, document.duration_seconds * 30)
    images = json.loads(task["image_asset_ids_json"])
    if document.first_frame_source == "selected" and document.first_frame_asset_id not in images:
        raise VideoAgentError("PROVIDER_REJECTED", "方案引用了不存在的首帧")
    if document.first_frame_source == "generate" and document.first_frame_asset_id is not None:
        raise VideoAgentError("PROVIDER_REJECTED", "未指定首帧时不能引用首帧素材")
    if document.music_asset_id:
        row = conn.execute("SELECT kind FROM assets WHERE asset_id=?", (document.music_asset_id,)).fetchone()
        if row is None or row["kind"] != "audio":
            raise VideoAgentError("PROVIDER_REJECTED", "方案引用了不存在的音频")


def _fail_planning(conn, task_id: str, work_id: str, error: VideoAgentError, now: str) -> None:
    retryable = 1 if error.code in {"PROVIDER_REJECTED", "PROVIDER_TEMPORARY", "PROVIDER_SUBMISSION_UNCERTAIN"} else 0
    conn.execute(
        """UPDATE tasks SET
            status='failed', stage='planning', stage_detail=NULL, failure_scope='planning',
            failure_code=?, failure_message=?, failure_stage='planning', failure_retryable=?,
            failure_details_json=?, questions_json='[]', completed_shots=NULL, total_shots=NULL,
            updated_at=?
           WHERE task_id=?""",
        (error.code, error.message, retryable, None if error.details is None else dumps(error.details), now, task_id),
    )
    _finish_work(conn, work_id)


def _finish_work(conn, work_id: str) -> None:
    conn.execute(
        "UPDATE work_items SET done=1, lease_owner=NULL, lease_until=NULL, next_attempt_at=NULL WHERE work_id=?",
        (work_id,),
    )

        return None
    return [str(item) for item in value]
```

```python
    def list_tasks(self) -> list[TaskSummary]:
        with self.db.transaction() as conn:
            rows = conn.execute("SELECT * FROM tasks ORDER BY updated_at DESC, task_id DESC").fetchall()
        summaries = []
        for row in rows:
            product = json.loads(row["product_info_json"])
            summaries.append(
                TaskSummary(
                    task_id=row["task_id"],
                    status=row["status"],
                    product_name=product.get("name"),
                    updated_at=row["updated_at"],
                )
            )
        return summaries

    def get_plan(self, task_id: str, plan_version: int) -> PlanView:
        with self.db.transaction() as conn:
            task = read_task_row(conn, task_id)
            row = conn.execute(
                "SELECT * FROM plan_versions WHERE task_id=? AND plan_version=?",
                (task_id, plan_version),
            ).fetchone()
            if row is None:
                raise VideoAgentError("NOT_FOUND", "方案不存在", task_id=task_id, plan_version=plan_version)
            return PlanView(
                task_id=task_id,
                plan_version=plan_version,
                is_head=task["head_plan_version"] == plan_version,
                confirmed=task["confirmed_plan_version"] == plan_version,
                abandoned=bool(row["abandoned"]),
                document=PlanDocument.model_validate_json(row["document_json"]),
            )

    def get_generation(self, generation_id: str) -> GenerationView:
        with self.db.transaction() as conn:
            row = conn.execute("SELECT * FROM generations WHERE generation_id=?", (generation_id,)).fetchone()
            if row is None:
                raise VideoAgentError("NOT_FOUND", "执行不存在", generation_id=generation_id)
            failure = None
            if row["failure_code"]:
                failure = FailureView(
                    code=row["failure_code"],
                    message=row["failure_message"] or "",
                    stage=row["failure_stage"],
                    retryable=bool(row["failure_retryable"]),
                )
            return GenerationView(
                generation_id=row["generation_id"],
                task_id=row["task_id"],
                plan_version=row["plan_version"],
                kind=row["kind"],
                shot_ids=json.loads(row["shot_ids_json"]),
                base_artifact_id=row["base_artifact_id"],
                status=row["status"],
                stage=row["stage"],
                stage_detail=row["stage_detail"],
                completed_shots=row["completed_shots"],
                total_shots=row["total_shots"],
                failure=failure,
            )

    def list_artifacts(self, task_id: str) -> list[ArtifactView]:
        with self.db.transaction() as conn:
            read_task_row(conn, task_id)
            rows = conn.execute(
                "SELECT * FROM artifacts WHERE task_id=? ORDER BY version DESC",
                (task_id,),
            ).fetchall()
        return [
            ArtifactView(
                artifact_id=row["artifact_id"],
                task_id=row["task_id"],
                generation_id=row["generation_id"],
                plan_version=row["plan_version"],
                version=row["version"],
                duration_seconds=row["duration_seconds"],
                aspect_ratio=row["aspect_ratio"],
                width=row["width"],
                height=row["height"],
                quality_status=row["quality_status"],
                quality=json.loads(row["quality_json"]),
                created_at=row["created_at"],
            )
            for row in rows
        ]

    def artifact_path(self, artifact_id: str) -> Path:
        with self.db.transaction() as conn:
            row = conn.execute("SELECT relative_path FROM artifacts WHERE artifact_id=?", (artifact_id,)).fetchone()
            if row is None:
                raise VideoAgentError("NOT_FOUND", "成品不存在")
            return self.files.path_for(row["relative_path"])
```
