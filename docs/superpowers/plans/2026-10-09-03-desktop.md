# 桌面测试台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个 Windows 桌面测试台，调用已经实现的 VideoAgent，走通登记图片、填写要求、修改和确认方案、查看进度、打开成片，并在不指定首帧时看到失败码。

**Architecture:** 界面用标准库 Tkinter，分成顶栏、左侧任务列表、中间需求/方案/执行和底部错误。按钮能否点击由无窗口纯函数计算，只看任务状态、是否已有确认方案、是否已有成功成品、FFmpeg 是否可用。每次点击生成一个新的幂等键，方法返回前按钮不可点。工人线程先 `recover()`，再循环 `tick()`，没有工作时休眠 1 秒。桌面只展示服务返回值，不另存一套任务状态，也不调用视频供应商。

**Tech Stack:** Python 3.11、标准库 Tkinter 与 threading、计划 1 和计划 2 已提供的 `video_agent`（Pydantic v2）。测试用 pytest，不创建 Tk 窗口。

## Global Constraints

- Python 3.11+。运行时依赖只有 `pydantic>=2` 和 `pillow>=10`。测试依赖 `pytest`。SQLite、Tkinter、哈希和路径使用标准库。
- 可执行文件是本机 PATH 上的 `ffmpeg` 和 `ffprobe`。帧率 30。成片是 H.264、yuv420p 的 MP4。有音轨时是 AAC、48 kHz、立体声。
- 默认视频码率 8_000_000 bps，默认音频码率 192_000 bps。
- 时长档默认 `[5, 10, 15, 30]`，默认选中 10。每一档是 1 到 30 的整数，含 30。档位不可重复，列表不可空，默认档必须属于档位。
- 画面比例只有 `9:16`、`16:9`、`1:1`、`4:5`、`3:4`、`4:3`、`3:2`、`2:3`。对应默认尺寸是 1080×1920、1920×1080、1080×1080、1080×1350、1080×1440、1440×1080、1620×1080、1080×1620。
- 覆盖某一档尺寸时，宽和高都是正偶数，并且 `width * ratio_h == height * ratio_w`。不能增删比例档。
- `max_images` 的允许范围是 1 到 12。`max_file_bytes` 的允许范围是 1 到 20971520。等于默认值合法，大于默认值拒绝。
- 数据目录默认是进程当前目录下的 `.video-agent/`，环境变量 `VIDEO_AGENT_HOME` 可改。配置缺失时写入默认 `config.json`。配置读不出或违反规则时抛出错误，不改写原文件。
- 密钥只放在该目录的 `config.json`。仓库忽略 `.video-agent/`。
- 租约默认 60 秒，配置值不得低于 15 秒。自动退避只追加 2 次，常量名 `MAX_AUTO_RETRIES`。
- 配音语速只允许 0.5 到 2.0 倍。仍放不进已确认区间时，错误码是 `VOICEOVER_DOES_NOT_FIT`。
- 幂等记录只在状态写入成功的同一事务里插入。校验失败和状态冲突不写幂等记录。重放检查在状态判断之前。重放返回当时存下的 `TaskView`，不新建规划或视频执行。
- 帧数分摊并列时，改镜头列表里下标最小的镜头。
- 错误码只用规格里的表：`VALIDATION_ERROR`、`NOT_FOUND`、`STATE_CONFLICT`、`PLAN_VERSION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`FIRST_FRAME_NOT_IMPLEMENTED`、`VOICEOVER_DOES_NOT_FIT`、`SHOT_DURATION_SHORT`、`ASSET_MISSING`、`PROVIDER_TEMPORARY`、`PROVIDER_REJECTED`、`PROVIDER_SUBMISSION_UNCERTAIN`、`MEDIA_EXPORT_FAILED`。不新增错误码。
- 不引入 Agent 编排框架，不实现 HTTP，不实现首帧生图，不写真实供应商报文。

## 契约决议

1. `VideoAgent` 没有返回数据目录的方法。内部函数 `desktop_app.viewmodel.resolve_home()` 重复契约规则：有环境变量 `VIDEO_AGENT_HOME` 就用它，否则用 `Path.cwd() / ".video-agent"`。启动时把这个 `Path` 传给 `VideoAgent(home=...)`、`load_config` 和 `save_settings`。不给 `video_agent` 增加公开名字。

2. 契约没有单独的“读取适配器额外字段”方法，`REAL_ADAPTERS` 为空。内部函数 `adapter_field_map` 从 `load_config` 的结果读取每个角色的 `adapter`，以及同级字符串字段、`fields` 字典或 Pydantic `model_extra`。`redact_secret_fields` 在放进控件之前，把键名包含 `key`、`token` 或 `secret` 的值换成空字符串。保存时这些空字符串原样放进 `AdapterSetting.fields`，由 `save_settings` 按契约保留原密钥。对话框不声明供应商报文；用户可以追加 `名称=值` 行，用来预先填写以后的真实适配器字段。

3. 已由契约覆盖。`TaskView` 含 `product_info`、`user_prompt`、`video_options`、`audio_options`、`image_asset_ids` 和 `first_frame_asset_id`。选中任务时用这些字段回填需求区，不要求用户重填品类、规格或自由描述。`product_name` 与 `product_info.name` 相同。镜头文案、比例适配和共享视觉设定只在有 head 时从 `get_plan(task_id, head_plan_version)` 回填。没有重新选图时，`InputPatch.images` 为 `None`。桌面仍不读 SQLite。实施任务 3 时按本条回填，不以旧说明为准。

## 桌面约束

- 本计划只新增 `desktop_app/` 和 `tests/test_viewmodel.py`。不改契约、规格、其他计划、`pyproject.toml` 和 `video_agent/`。
- 计划 1 与计划 2 已经提供契约里的 `VideoAgent`。桌面调用 `list_tasks`、`register_asset`、`create_task`、`get_task`、`submit_inputs`、`retry_planning`、`get_plan`、`revise_plan`、`discard_revision`、`confirm`、`regenerate`、`retry_generation`、`list_artifacts`、`artifact_path`、`tick`、`recover`，以及 `video_agent.config.load_config`、`video_agent.config.save_settings`、`video_agent.media.ffmpeg_available`。
- 不调用规划器、视频供应商、配音、音乐、视觉检查、`pipeline` 或 SQLite。
- 窗口标题是 `视频生成测试台`。底部只在 `status=="failed"` 时显示失败的 `code`、`message`、`stage`。`awaiting_input` 的 `questions` 显示在中间。
- 自然语言句子去掉首尾空白后非空时，只提交 `PlanChange(instruction=...)`。句子为空时提交结构化 `PlanPatch`。
- 按镜头重生成的勾选来自最新成功成品的 `plan_version`，不来自未确认 head。没有成功成品时该按钮不可点。
- FFmpeg 不可用时不能创建、确认、重生成或重试执行。可以查看任务、按状态补充或修改、放弃草稿、重试规划，并打开已有成片。
- `failure.retryable` 不参与按钮计算。`FIRST_FRAME_NOT_IMPLEMENTED` 时重试执行按钮仍按写入表可点，点击后由服务返回 `STATE_CONFLICT`。
- 一次点击调用 `new_idempotency_key()` 一次。该方法返回前，写入类按钮不可点。
- 入口是 `python -m desktop_app`。成片用 `os.startfile` 打开。
- `tests/test_viewmodel.py` 不导入 Tkinter，不构造 `Tk`。

```python
from __future__ import annotations

import os
import uuid
from dataclasses import dataclass
from pathlib import Path

from video_agent.models import TaskView

POLL_INTERVAL_MS = 1000
IDLE_SLEEP_SECONDS = 1


@dataclass(frozen=True)
class ButtonStates:
    create: bool
    submit_inputs: bool
    revise_plan: bool
    confirm: bool
    discard_revision: bool
    regenerate_full: bool
    regenerate_shots: bool
    retry_planning: bool
    retry_generation: bool
    open_artifact: bool


def button_states(
    *,
    status: str | None,
    failure_scope: str | None,
    has_head: bool,
    head_confirmed: bool,
    has_confirmed_plan: bool,
    has_successful_artifact: bool,
    ffmpeg_available: bool,
) -> ButtonStates:
    can_regenerate = has_confirmed_plan and ffmpeg_available
    shots = can_regenerate and has_successful_artifact
    submit_inputs = False
    revise_plan = False
    confirm = False
    discard_revision = False
    regenerate_full = False
    regenerate_shots = False
    retry_planning = False
    retry_generation = False

    if status == "awaiting_input":
        submit_inputs = True
        discard_revision = has_confirmed_plan
    elif status == "awaiting_confirmation":
        revise_plan = True
        confirm = ffmpeg_available
        discard_revision = has_confirmed_plan
        regenerate_full = can_regenerate
        regenerate_shots = shots
    elif status == "succeeded":
        revise_plan = True
        regenerate_full = can_regenerate
        regenerate_shots = shots
    elif status == "failed" and failure_scope == "planning":
        retry_planning = True
        submit_inputs = not has_head
        revise_plan = has_head
        discard_revision = has_confirmed_plan
    elif status == "failed" and failure_scope == "generation":
        retry_generation = ffmpeg_available
        revise_plan = True
        regenerate_full = can_regenerate
        regenerate_shots = shots
        head_open = has_head and not head_confirmed
        confirm = head_open and ffmpeg_available
        discard_revision = head_open and has_confirmed_plan

    return ButtonStates(
        create=ffmpeg_available,
        submit_inputs=submit_inputs,
        revise_plan=revise_plan,
        confirm=confirm,
        discard_revision=discard_revision,
        regenerate_full=regenerate_full,
        regenerate_shots=regenerate_shots,
        retry_planning=retry_planning,
        retry_generation=retry_generation,
        open_artifact=has_successful_artifact,
    )


def button_states_for(
    task: TaskView | None,
    *,
    has_successful_artifact: bool,
    ffmpeg_available: bool,
) -> ButtonStates:
    if task is None:
        return button_states(
            status=None,
            failure_scope=None,
            has_head=False,
            head_confirmed=False,
            has_confirmed_plan=False,
            has_successful_artifact=has_successful_artifact,
            ffmpeg_available=ffmpeg_available,
        )
    has_head = task.head_plan_version is not None
    has_confirmed_plan = task.confirmed_plan_version is not None
    head_confirmed = has_head and task.head_plan_version == task.confirmed_plan_version
    return button_states(
        status=task.status,
        failure_scope=task.failure_scope,
        has_head=has_head,
        head_confirmed=head_confirmed,
        has_confirmed_plan=has_confirmed_plan,
        has_successful_artifact=has_successful_artifact,
        ffmpeg_available=ffmpeg_available,
    )


def failure_text(task: TaskView | None) -> tuple[str, str, str]:
    if task is None or task.status != "failed" or task.failure is None:
        return ("", "", "")
    return (task.failure.code, task.failure.message, task.failure.stage or "")


def question_text(task: TaskView | None) -> str:
    if task is None or task.status != "awaiting_input":
        return ""
    return "\n".join(task.questions)


def error_dialog_text(code: str, message: str, stage: str | None) -> str:
    return f"{code}\n{message}\n{stage or ''}"


def should_poll(status: str | None) -> bool:
    return status in {"pending", "planning", "generating"}


def new_idempotency_key() -> str:
    return uuid.uuid4().hex


def command_enabled(allowed: bool, busy: bool) -> bool:
    return allowed and not busy


def resolve_home() -> Path:
    raw = os.environ.get("VIDEO_AGENT_HOME")
    if raw:
        return Path(raw)
    return Path.cwd() / ".video-agent"
```

```python
            return

        if not self._busy and self.selected_id is not None:
            self.refresh_tasks()
            self.reload_selected()
            return
        self._ensure_poll()

        if self._poll_job is not None:
            self.after_cancel(self._poll_job)
        self.stop_event.set()
        self.destroy()
```

```python
from video_agent.config import AdapterSetting, SettingsPatch

SETTINGS_ROLES = (
    ("planner", "规划"),
    ("video", "视频"),
    ("voice", "配音"),
    ("music", "音乐"),
    ("visual", "视觉检查"),
)
_SECRET_MARKERS = ("key", "token", "secret")


@dataclass
class AdapterEdit:
    adapter: str
    fields: dict[str, str]


@dataclass
class SettingsEdit:
    duration_tiers: list[int]
    default_duration: int
    mode: str
    planner: AdapterEdit
    video: AdapterEdit
    voice: AdapterEdit
    music: AdapterEdit
    visual: AdapterEdit


def is_secret_field(name: str) -> bool:
    lowered = name.lower()
    return any(marker in lowered for marker in _SECRET_MARKERS)


def redact_secret_fields(fields: dict[str, str]) -> dict[str, str]:
    shown = {}
    for key, value in fields.items():
        shown[key] = "" if is_secret_field(key) else value
    return shown


def _read(obj: object, name: str, default=None):
    if isinstance(obj, dict):
        return obj.get(name, default)
    return getattr(obj, name, default)


def adapter_field_map(adapter_value: object) -> tuple[str, dict[str, str]]:
    if adapter_value is None:
        return "", {}
    if isinstance(adapter_value, dict):
        name = str(adapter_value.get("adapter", ""))
        nested = adapter_value.get("fields")
        raw = nested if isinstance(nested, dict) else adapter_value
    else:
        name = str(getattr(adapter_value, "adapter", ""))
        nested = getattr(adapter_value, "fields", None)
        if isinstance(nested, dict):
            raw = nested
        else:
            extra = getattr(adapter_value, "model_extra", None) or {}
            raw = {}
            for key in dir(adapter_value):
                if key.startswith("_"):
                    continue
                value = getattr(adapter_value, key, None)
                if isinstance(value, str):
                    raw[key] = value
            for key, value in dict(extra).items():
                if isinstance(value, str):
                    raw[str(key)] = value
    fields = {}
    for key, value in raw.items():
        if key in {"adapter", "fields"}:
            continue
        if isinstance(value, str):
            fields[str(key)] = value
    return name, fields


def settings_form_from_mapping(config: object) -> SettingsEdit:
    adapters = _read(config, "adapters")

    def role(role_name: str) -> AdapterEdit:
        adapter_name, fields = adapter_field_map(_read(adapters, role_name))
        return AdapterEdit(adapter=adapter_name, fields=redact_secret_fields(fields))

    return SettingsEdit(
        duration_tiers=list(_read(config, "duration_tiers")),
        default_duration=int(_read(config, "default_duration")),
        mode=str(_read(config, "mode")),
        planner=role("planner"),
        video=role("video"),
        voice=role("voice"),
        music=role("music"),
        visual=role("visual"),
    )


def fields_to_text(fields: dict[str, str]) -> str:
    return "\n".join(f"{key}={value}" for key, value in fields.items())


def parse_field_lines(text: str) -> dict[str, str]:
    fields = {}
    for line in text.splitlines():
        if not line.strip() or "=" not in line:
            continue
        key, value = line.split("=", 1)
        fields[key.strip()] = value
    return fields


def parse_duration_tiers(text: str) -> list[int]:
    return [int(part.strip()) for part in text.split(",") if part.strip()]


def format_duration_tiers(tiers: list[int]) -> str:
    return ",".join(str(item) for item in tiers)


def mode_from_label(label: str) -> str:
    for mode, text in MODE_CHOICES:
        if label == text:
            return mode
    raise ValueError(label)


def build_settings_patch(edit: SettingsEdit) -> SettingsPatch:
    def one(item: AdapterEdit) -> AdapterSetting:
        return AdapterSetting(adapter=item.adapter.strip(), fields=dict(item.fields))

    return SettingsPatch(
        duration_tiers=list(edit.duration_tiers),
        default_duration=edit.default_duration,
        mode=edit.mode,
        planner=one(edit.planner),
        video=one(edit.video),
        voice=one(edit.voice),
        music=one(edit.music),
        visual=one(edit.visual),
    )
```

```python
from __future__ import annotations

import threading
from collections.abc import Callable

from desktop_app.viewmodel import IDLE_SLEEP_SECONDS


def tick_loop(agent, stop_event: threading.Event, sleep: Callable[[float], None] | None = None) -> None:
    while not stop_event.is_set():
        result = agent.tick()
        if result.did_work:
            continue
        if sleep is None:
            stop_event.wait(IDLE_SLEEP_SECONDS)
        else:
            sleep(IDLE_SLEEP_SECONDS)


def start_worker(agent, stop_event: threading.Event, sleep: Callable[[float], None] | None = None) -> threading.Thread:
    agent.recover()
    thread = threading.Thread(
        target=tick_loop,
        args=(agent, stop_event, sleep),
        name="video-agent-worker",
        daemon=True,
    )
    thread.start()
    return thread
```
