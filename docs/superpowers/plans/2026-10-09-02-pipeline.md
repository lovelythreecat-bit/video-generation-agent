# 成片链路 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现替身规划、替身视频、替身配音、替身音乐、无视觉检查、FFmpeg 媒体函数和生成步骤，使指定首帧的任务导出帧数等于已确认秒数乘以 30 的 MP4。

**Architecture:** 计划 1 的 `tick` 在领取到 `kind=generation` 的工作后调用 `advance_generation`。该函数每次只推进一个阶段：确定首帧、提交一个镜头、导入一个镜头、准备音频、拼接无字幕画面、视觉检查、导出。`fake` 模式由工厂固定装上四个替身和 `NoneVisual`。画面适配、拼接、字幕、混音和成片检查都调用本机 FFmpeg。未指定首帧时在 `first_frame` 步失败，不调用视频模型。

**Tech Stack:** Python 3.11+、Pydantic v2、Pillow、标准库 `sqlite3`、`wave`、`subprocess`。成片工具是本机 PATH 上的 `ffmpeg` 与 `ffprobe`。测试使用 pytest。

## 契约决议

契约没有写出下列签名。本计划用内部辅助函数和这些调用约定补上，不改公开名字。

- `advance_generation(agent: VideoAgent, work_id: str) -> str` 执行该工作当前的一个 `step`，返回执行前的步骤名。计划 1 的 `tick` 在 `kind=generation` 时调用它。
- `VideoAgent` 上已有属性：`home: Path`、`files`、`db`、`clock`、`config`、`worker_owner: str`、`video`、`voice`、`music`、`visual`。生成步骤使用这些实例，不按 `copied_config_json` 重新构造适配器。
- 实施时以计划 1 为准。数据库只有 `transaction()`、`_conn` 和 `_lock`，文件库只有 `home`。`_transaction` 调用 `agent.db.transaction()`。路径用 `agent.files.home`。不要先持有 `db.lock` 再调用 `transaction()`，这把锁不可重入。适配器额外字段写在角色对象上，与 `adapter` 同级，例如 `config.adapters["voice"].field_map()` 里的 `base_url`，不嵌在 `fields` 里。`snapshot_config` 只含 `mode` 和 `adapters`。
- `AppConfig` 的读取路径是 `mode`、`video_bitrate`、`audio_bitrate`、`lease_seconds`、`resolutions`，以及 `adapters` 下每个角色的 `adapter` 和同级额外字段。
- 码率和分辨率从当前 `AppConfig` 读取。抄进工作的配置里没有这两项。
- `REAL_ADAPTERS` 的值可以带 `required_fields: tuple[str, ...]` 和 `build(fields: dict[str, str]) -> object`。字典本身保持 `{}`。本计划不写真实供应商报文。
- 替身类名 `FakePlanner`、`FakeVideo`、`FakeVoice`、`FakeMusic` 和 `NoneVisual` 是模块内实现名。适配器公开名字仍是 `fake` 和 `none`。
- 视觉适配器名 `fake` 和 `none` 都返回 `NoneVisual`。本计划没有会打分的视觉替身。
- `fit="native"` 且源图宽高比与目标相同时，等比缩放到目标尺寸。比例不同时按 `pad` 处理，避免拉伸。
- 汉字数与拉丁字母数相等时，该侧没有主语言，不参与冲突判断。`PlanRequest.images` 只有素材标识；替身规划不打开图片，也不判断看不清外观。
- `revise` 无法解释时返回 `patch is None` 且 `questions is None`。计划 1 把它写成 `PROVIDER_REJECTED`。
- 合法档位不超过 30 秒，替身规划始终产出一个镜头 `s1`。
- 确认时如果还没有 `generation_shots` 行，`first_frame` 步按快照插入，`status=pending`，`ordinal` 从 0 开始。
- 原始首帧拷贝使用契约路径 `first_frame{ext}`。适配后的画面写到同目录的 `first_frame_fitted.png`。视觉结果写到同目录的 `quality.json`。检查通过前的成片写到 `final.tmp.mp4`，通过后替换为 `final.mp4`。检查失败时删除 `final.tmp.mp4`，保留镜头、音频和 `composed.mp4`。
- 每个镜头的 `tail_frame_path` 都是 `None`。相邻帧只属于计划 4 的局部重生成。
- 替身视频的中间片段码率是 `500_000`。成片导出使用配置里的 `video_bitrate`。替身配音每个非空白字符 100 毫秒，最短 400 毫秒，一个 cue 从 0 覆盖整段，正弦波 1000 Hz。替身音乐是 200 Hz。
- `ProbeInfo.audio_codec` 在没有音轨时是 `None`。像素格式和帧率不放进 `ProbeInfo`；内部函数 `_pixel_format` 与 `_frame_rate` 用 ffprobe 读取，导出检查要求 `yuv420p` 和 30 fps。配音垫静音、语速和音频拼接使用内部函数 `_silence`、`_atempo_pad`、`_concat_audio`。音乐循环仍走公开的 `trim_or_loop_audio`。
- `generations.snapshot_json` 是 `PlanDocument` 的 JSON，用 `PlanDocument.model_validate_json` 读取。
- 计划 1 在调用 `advance_generation` 前已经提交领取事务，连接处于自动提交状态。`hold_lease` 退出时停止并 join 续租线程；本计划在它退出之后才清空租约。
- 语音中间文件可以是 `voice-{shot_id}.m4a`。最终配音仍是契约路径 `voice.m4a`。
- 计划 1 的 `claim_next` 只领取 `done=0`、`next_attempt_at` 为空或已到期、且租约为空或已过期的工作。查询返回 `pending` 时，本计划把 `next_attempt_at` 写成当前时间加 1 秒，并把租约续到 `now + lease_seconds`。测试把 `lease_seconds` 写成 15，用 `FrozenClock.advance(16)` 越过租约后再领取。
- 本计划不实现局部重生成、租约心跳、自动退避和不确定提交后的只查询循环。阻塞调用仍然放进计划 1 已提供的 `hold_lease`。`SHOT_DURATION_SHORT`、`PROVIDER_TEMPORARY` 和其他可重试错误在本计划里直接写成 `failed`，不增加 `auto_attempts_used`。`submit_shot` 返回 `uncertain=True`，或导入时没有 `external_task_id`，本计划把 `submission_state` 写成 `uncertain` 并让执行以 `PROVIDER_SUBMISSION_UNCERTAIN` 失败，不再次提交。计划 4 再改成退避、续租心跳，以及查询到 `absent` 之后才允许提交。

## Global Constraints

- Python 3.11+。运行时依赖只有 `pydantic>=2` 和 `pillow>=10`。测试依赖 `pytest`。SQLite、Tkinter、哈希和路径使用标准库。
- 可执行文件是本机 PATH 上的 `ffmpeg` 和 `ffprobe`。帧率 30。成片是 H.264、yuv420p 的 MP4。有音轨时是 AAC、48 kHz、立体声。
- 默认视频码率 8_000_000 bps，默认音频码率 192_000 bps。
- 时长档默认 `[5, 10, 15, 30]`，默认选中 10。每一档是 1 到 30 的整数，含 30。档位不可重复，列表不可空，默认档必须属于档位。
- 画面比例只有 `9:16`、`16:9`、`1:1`、`4:5`、`3:4`、`4:3`、`3:2`、`2:3`。对应默认尺寸是 1080×1920、1920×1080、1080×1080、1080×1350、1080×1440、1440×1080、1620×1080、1080×1620。
- 覆盖某一档尺寸时，宽和高都是正偶数，并且 `width * ratio_h == height * ratio_w`。不能增删比例档。
- `max_images` 的允许范围是 1 到 12。`max_file_bytes` 的允许范围是 1 到 20971520。等于默认值合法，大于默认值拒绝。
- 数据目录默认是进程当前目录下的 `.video-agent/`，环境变量 `VIDEO_AGENT_HOME` 可改。配置缺失时写入默认 `config.json`。配置读不出或违反规则时抛出错误，不改写原文件。
- 密钥只放在该目录的 `config.json`。仓库忽略 `.video-agent/`。
- 租约默认 60 秒，配置值不得低于 15 秒。自动退避只追加 2 次，常量名 `MAX_AUTO_RETRIES`。
- 配音语速只允许 0.5 到 2.0 倍。仍放不进已确认区间时，错误码是 `VOICEOVER_DOES_NOT_FIT`。
- 幂等记录只在状态写入成功的同一事务里插入。校验失败和状态冲突不写幂等记录。重放检查在状态判断之前。重放返回当时存下的 `TaskView`，不新建规划或视频执行。
- 帧数分摊并列时，改镜头列表里下标最小的镜头。
- 错误码只用规格里的表：`VALIDATION_ERROR`、`NOT_FOUND`、`STATE_CONFLICT`、`PLAN_VERSION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`FIRST_FRAME_NOT_IMPLEMENTED`、`VOICEOVER_DOES_NOT_FIT`、`SHOT_DURATION_SHORT`、`ASSET_MISSING`、`PROVIDER_TEMPORARY`、`PROVIDER_REJECTED`、`PROVIDER_SUBMISSION_UNCERTAIN`、`MEDIA_EXPORT_FAILED`。不新增错误码。
- 不引入 Agent 编排框架，不实现 HTTP，不实现首帧生图，不写真实供应商报文。

以下命令都在仓库根目录执行。计划 1 的 `pyproject.toml` 已经把仓库根放进 pytest 的 `pythonpath`。本计划不修改该文件。

媒体测试不使用 `pytest.importorskip` 探测可执行文件。`ffmpeg` 和 `ffprobe` 不是 Python 模块。每个需要它们的测试在开头执行 `shutil.which("ffmpeg")` 和 `shutil.which("ffprobe")`，任一为 `None` 就 `pytest.skip("ffmpeg and ffprobe are required")`。字幕测试在 `C:\Windows\Fonts` 里找不到 `msyh.ttc`、`msyh.ttf`、`simhei.ttf`、`segoeui.ttf`、`arial.ttf` 时，再跳过绘制断言。

```python
from __future__ import annotations

from video_agent.config import AppConfig
from video_agent.errors import VideoAgentError
from video_agent.ports import MusicProvider, Planner, VideoProvider, VisualChecker, VoiceProvider

REAL_ADAPTERS: dict[str, object] = {}


def build_adapters(
    config: AppConfig,
) -> tuple[Planner, VideoProvider, VoiceProvider | None, MusicProvider | None, VisualChecker | None]:
    if config.mode == "fake":
        from video_agent.fake_music import FakeMusic
        from video_agent.fake_planner import FakePlanner
        from video_agent.fake_video import FakeVideo
        from video_agent.fake_voice import FakeVoice
        from video_agent.visual import NoneVisual

        return FakePlanner(), FakeVideo(), FakeVoice(), FakeMusic(), NoneVisual()

    planner = _build_required(config.adapters["planner"].adapter, config.adapters["planner"].field_map())
    video = _build_required(config.adapters["video"].adapter, config.adapters["video"].field_map())
    voice = _build_optional(config.adapters["voice"].adapter, config.adapters["voice"].field_map(), _fake_voice, None)
    music = _build_optional(config.adapters["music"].adapter, config.adapters["music"].field_map(), _fake_music, None)
    visual = _build_optional(
        config.adapters["visual"].adapter,
        config.adapters["visual"].field_map(),
        _none_visual,
        _none_visual(),
    )
    return planner, video, voice, music, visual


def _fake_voice() -> VoiceProvider:
    from video_agent.fake_voice import FakeVoice

    return FakeVoice()


def _fake_music() -> MusicProvider:
    from video_agent.fake_music import FakeMusic

    return FakeMusic()


def _none_visual() -> VisualChecker:
    from video_agent.visual import NoneVisual

    return NoneVisual()


def _build_required(name: str, fields: dict[str, str]) -> object:
    if name in {"fake", "none"} or name not in REAL_ADAPTERS:
        raise VideoAgentError("VALIDATION_ERROR", "没有已注册的真实规划或视频适配器")
    return _invoke(name, fields)


def _build_optional(name: str, fields: dict[str, str], fake_factory, none_value):
    if name == "none":
        return none_value
    if name == "fake":
        return fake_factory()
    if name not in REAL_ADAPTERS:
        raise VideoAgentError("VALIDATION_ERROR", "没有已注册的真实规划或视频适配器")
    return _invoke(name, fields)


def _invoke(name: str, fields: dict[str, str]) -> object:
    spec = REAL_ADAPTERS[name]
    required = tuple(getattr(spec, "required_fields", ()))
    missing = [key for key in required if not str(fields.get(key, "")).strip()]
    if missing:
        raise VideoAgentError("VALIDATION_ERROR", "缺少必填项: " + ",".join(missing), fields=missing)
    build = getattr(spec, "build", None)
    if not callable(build):
        raise VideoAgentError("VALIDATION_ERROR", "没有已注册的真实规划或视频适配器")
    return build(fields)
```

        used = False

        if seconds:
            value = int(seconds[0])
            if value not in request.duration_tiers:
                tiers = "、".join(str(item) for item in request.duration_tiers)
                return ReviseResult(questions=[f"时长只能选择 {tiers} 秒"])

                patch.fit = "native" if ratio in request.video_capabilities.native_aspects else "pad"
                used = True

    parts = [info.name or "", info.category or "", info.specs or "", *info.selling_points, *info.extra.values()]
    return "\n".join(parts)


def _language_of(text: str) -> str | None:
    han = len(re.findall(r"[\u4e00-\u9fff]", text))
    latin = len(re.findall(r"[A-Za-z]", text))
    if han == 0 and latin == 0:
        return None
    if han == latin:
        return None
    return "zh" if han > latin else "en"


def _language_conflict(info: ProductInfo, prompt: str) -> str | None:
    product = _language_of(_product_text(info))
    user = _language_of(prompt)
    if product is None or user is None or product == user:
        return None
    names = {"zh": "中文", "en": "英文"}
    return f"产品资料主语言是{names[product]}，用户要求主语言是{names[user]}，请明确配音和字幕语言"


def _capabilities(note: str, request: PlanRequest) -> str:
    foreign = []
    for match in re.findall(r"(\d+)\s*秒", request.user_prompt):
        value = int(match)
        if value not in request.duration_tiers and value not in foreign:
            foreign.append(value)
    if not foreign:
        return note
    tiers = "、".join(str(item) for item in request.duration_tiers)
    found = "、".join(str(item) for item in foreign)
    return f"{note}。当前时长档位为 {tiers} 秒，描述中的 {found} 秒不会作为目标时长"

def fit_image(image: Path, fit: Literal["native", "pad", "crop"], width: int, height: int, dest: Path) -> None:
    source = Image.open(image).convert("RGB")
    src_w, src_h = source.size
    if src_w <= 0 or src_h <= 0 or width <= 0 or height <= 0:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "图片尺寸无效", retryable=True)
    mode = fit
    if fit == "native":
        mode = "native" if src_w * height == src_h * width else "pad"
    dest.parent.mkdir(parents=True, exist_ok=True)
    if mode == "native":
        source.resize((width, height), Image.Resampling.LANCZOS).save(dest, format="PNG")
        return
    if mode == "crop":
        scale = max(width / src_w, height / src_h)
        new_w = max(width, math.ceil(src_w * scale - 1e-9))
        new_h = max(height, math.ceil(src_h * scale - 1e-9))
        resized = source.resize((new_w, new_h), Image.Resampling.LANCZOS)
        left = max(0, (new_w - width) // 2)
        top = max(0, (new_h - height) // 2)
        resized.crop((left, top, left + width, top + height)).save(dest, format="PNG")
        return
    scale = min(width / src_w, height / src_h)
    new_w = min(width, max(1, math.floor(src_w * scale)))
    new_h = min(height, max(1, math.floor(src_h * scale)))
    canvas = Image.new("RGB", (width, height), (0, 0, 0))
    canvas.paste(source.resize((new_w, new_h), Image.Resampling.LANCZOS), ((width - new_w) // 2, (height - new_h) // 2))
    canvas.save(dest, format="PNG")

def _music_gain(ms: float, cues: list[VoiceCue]) -> float:
    gain = 1.0
    for cue in cues:
        pre = cue.start_ms - 200
        post = cue.end_ms + 200
        if ms < pre or ms > post:
            continue
        if ms < cue.start_ms:
            local = 1.0 - 0.75 * (ms - pre) / 200.0
        elif ms <= cue.end_ms:
            local = 0.25
        else:
            local = 0.25 + 0.75 * (ms - cue.end_ms) / 200.0
        if local < gain:
            gain = local
    return gain


def _duck_wav(src: Path, cues: list[VoiceCue], dest: Path) -> None:
    with wave.open(str(src), "rb") as handle:
        channels = handle.getnchannels()
        rate = handle.getframerate()
        width = handle.getsampwidth()
        frames = handle.getnframes()
        raw = handle.readframes(frames)
    if width != 2 or channels < 1:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "音乐必须是 16 位 PCM", retryable=True)
    samples = struct.unpack("<" + "h" * (len(raw) // 2), raw)
    out = bytearray()
    for index in range(frames):
        gain = _music_gain(index * 1000.0 / rate, cues)
        base = index * channels
        for channel in range(channels):
            value = int(samples[base + channel] * gain)
            value = max(-32768, min(32767, value))
            out += struct.pack("<h", value)
    with wave.open(str(dest), "wb") as handle:
        handle.setnchannels(channels)
        handle.setsampwidth(2)
        handle.setframerate(rate)
        handle.writeframes(bytes(out))

def _font_file(text: str) -> tuple[str, Path]:
    needed = {ord(ch) for ch in text if not ch.isspace()}
    for family, names in FONT_FILES:
        for name in names:
            path = FONT_DIR / name

def _font_covers(path: Path, needed: set[int]) -> bool:
    if not needed:
        return True
    data = path.read_bytes()
    return any(_font_covers_at(data, offset, needed) for offset in _font_offsets(data))


def _font_offsets(data: bytes) -> list[int]:
    if data[:4] == b"ttcf":
        count = struct.unpack_from(">I", data, 8)[0]
        return list(struct.unpack_from(f">{count}I", data, 12))
    return [0]


def _font_covers_at(data: bytes, font_offset: int, needed: set[int]) -> bool:
    num_tables = struct.unpack_from(">H", data, font_offset + 4)[0]
    cmap_offset = None
    cursor = font_offset + 12
    for _index in range(num_tables):
        tag, _checksum, offset, _length = struct.unpack_from(">4sIII", data, cursor)
        cursor += 16
        if tag == b"cmap":
            cmap_offset = offset
            break
    if cmap_offset is None:
        return False
    count = struct.unpack_from(">H", data, cmap_offset + 2)[0]
    for index in range(count):
        _platform, _encoding, sub_offset = struct.unpack_from(">HHI", data, cmap_offset + 4 + index * 8)
        absolute = cmap_offset + sub_offset
        fmt = struct.unpack_from(">H", data, absolute)[0]
        if fmt == 4 and _format4_covers(data, absolute, needed):
            return True
        if fmt == 12 and _format12_covers(data, absolute, needed):
            return True
    return False


def _format4_covers(data: bytes, offset: int, needed: set[int]) -> bool:
    seg_count = struct.unpack_from(">H", data, offset + 6)[0] // 2
    end_at = offset + 14
    ends = struct.unpack_from(f">{seg_count}H", data, end_at)
    start_at = end_at + seg_count * 2 + 2
    starts = struct.unpack_from(f">{seg_count}H", data, start_at)
    delta_at = start_at + seg_count * 2
    deltas = struct.unpack_from(f">{seg_count}h", data, delta_at)
    range_at = delta_at + seg_count * 2
    range_offsets = struct.unpack_from(f">{seg_count}H", data, range_at)
    for code in needed:
        if code > 0xFFFF or not _format4_has(data, code, ends, starts, deltas, range_offsets, range_at):
            return False
    return True


def _format4_has(data: bytes, code: int, ends, starts, deltas, range_offsets, range_at: int) -> bool:
    for index, (start, end) in enumerate(zip(starts, ends)):
        if code < start or code > end:
            continue
        if range_offsets[index] == 0:
            return ((code + deltas[index]) & 0xFFFF) != 0
        position = range_at + index * 2 + range_offsets[index] + (code - start) * 2
        glyph = struct.unpack_from(">H", data, position)[0]
        if glyph == 0:
            return False
        return ((glyph + deltas[index]) & 0xFFFF) != 0
    return False


def _format12_covers(data: bytes, offset: int, needed: set[int]) -> bool:
    groups = struct.unpack_from(">I", data, offset + 12)[0]
    cursor = offset + 16
    spans = []
    for _index in range(groups):
        start, end, glyph = struct.unpack_from(">III", data, cursor)
        cursor += 12
        spans.append((start, end, glyph))
    for code in needed:
        if not any(start <= code <= end and glyph + (code - start) != 0 for start, end, glyph in spans):
            return False
    return True


def _wrap_line(text: str, font: ImageFont.FreeTypeFont, max_width: float) -> list[str]:
    lines: list[str] = []
    current = ""
    for char in text.replace("\n", ""):
        if font.getlength(char) > max_width:
            raise VideoAgentError("MEDIA_EXPORT_FAILED", "换行后的字幕放不进画面", stage="exporting", retryable=True)
        trial = current + char
        if current and font.getlength(trial) > max_width:
            lines.append(current)
            current = char
        else:
            current = trial
    if current:
        lines.append(current)
    return lines or [""]


def _ass_document(width: int, height: int, family: str, font_size: int, margin_v: int, events: list[str]) -> str:
    header = "\n".join(
        [
            "[Script Info]",
            "ScriptType: v4.00+",
            f"PlayResX: {width}",
            f"PlayResY: {height}",
            "WrapStyle: 2",
            "",
            "[V4+ Styles]",
            "Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding",
            f"Style: Default,{family},{font_size},&H00FFFFFF,&H000000FF,&H00000000,&H00000000,0,0,0,0,100,100,0,0,1,2,0,2,10,10,{margin_v},1",
            "",
            "[Events]",
            "Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text",
            *events,
            "",
        ]
    )
    return header


def _ass_time(ms: int) -> str:
    centi = max(0, ms) // 10
    seconds, centi = divmod(centi, 100)
    minutes, seconds = divmod(seconds, 60)
    hours, minutes = divmod(minutes, 60)
    return f"{hours}:{minutes:02d}:{seconds:02d}.{centi:02d}"


def _ass_text(lines: list[str]) -> str:
    escaped = [line.replace("\\", r"\\").replace("{", r"\{").replace("}", r"\}") for line in lines]
    return r"\N".join(escaped)


def _filter_path(path: Path) -> str:
    text = path.resolve().as_posix()
    if len(text) >= 2 and text[1] == ":":
        text = text[0] + r"\:" + text[2:]
    return text.replace("'", r"\'")

def _streams(path: Path) -> tuple[dict | None, dict | None]:
    if shutil.which("ffprobe") is None:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "找不到 ffprobe", retryable=True)
    completed = subprocess.run(
        [
            "ffprobe", "-v", "error", "-count_frames", "-print_format", "json",
            "-show_streams",
            "-show_entries", "stream=codec_type,codec_name,width,height,nb_read_frames,pix_fmt,avg_frame_rate",
            str(path),
        ],
        capture_output=True,
        check=False,
        stdin=subprocess.DEVNULL,
    )
    if completed.returncode != 0:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "ffprobe 无法解码", retryable=True)
    payload = json.loads(completed.stdout.decode("utf-8"))
    video = None
    audio = None
    for stream in payload.get("streams", []):
        if stream.get("codec_type") == "video" and video is None:
            video = stream
        elif stream.get("codec_type") == "audio" and audio is None:
            audio = stream
    return video, audio


def _run_ffmpeg(args: list[str]) -> None:
    if shutil.which("ffmpeg") is None:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "找不到 ffmpeg", retryable=True)
    completed = subprocess.run(
        ["ffmpeg", "-y", *args],
        capture_output=True,
        check=False,
        stdin=subprocess.DEVNULL,
    )
    if completed.returncode != 0:
        tail = completed.stderr.decode("utf-8", errors="replace")[-500:]
        raise VideoAgentError("MEDIA_EXPORT_FAILED", f"ffmpeg 失败: {tail}", retryable=True)

        self._by_external: dict[str, ShotRequest] = {}

    def capabilities(self) -> VideoCapabilities:

            native_aspects=["9:16"],

            supports_first_frame=True,
            supports_reference_images=True,

            return SubmitResult(external_task_id=existing[0], uncertain=False)
        external_task_id = str(uuid.uuid4())
        self._by_key[request.provider_idempotency_key] = (external_task_id, request)
        self._by_external[external_task_id] = request
        return SubmitResult(external_task_id=external_task_id, uncertain=False)

    def query(self, *, external_task_id: str | None, provider_idempotency_key: str) -> QueryResult:
        if provider_idempotency_key in self._by_key or (
            external_task_id is not None and external_task_id in self._by_external
        ):
            return QueryResult(state="succeeded")
        return QueryResult(state="absent", message="外部任务不存在")

import json

from video_agent.errors import VideoAgentError

    "first_frame": "preparing_first_frame",
    "submit_shot": "generating_shots",
    "import_shot": "generating_shots",
    "audio": "preparing_audio",
    "compose": "composing",

    "audio": "正在准备音频",

def advance_generation(agent, work_id: str) -> str:
    work = _load_work(agent, work_id)
    step = str(work["step"])
    try:
        _dispatch(agent, work, step)
    except VideoAgentError as exc:
        _fail(agent, work, exc)
    except Exception as exc:
        _fail(
            agent,
            work,
            VideoAgentError("MEDIA_EXPORT_FAILED", str(exc), stage=_STAGE.get(step), retryable=True),
        )
    return step


def _dispatch(agent, work: dict, step: str) -> None:
    if step == "first_frame":
        _step_first_frame(agent, work)
        return
    raise VideoAgentError(
        "MEDIA_EXPORT_FAILED",
        f"未知生成步骤 {step}",
        stage=_STAGE.get(step),
        retryable=False,
    )


def _step_first_frame(agent, work: dict) -> None:
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    _ensure_shots(agent, work["generation_id"], document)
    _enter(agent, work, "first_frame")
    if document.first_frame_source != "selected" or not document.first_frame_asset_id:
        raise VideoAgentError(
            "FIRST_FRAME_NOT_IMPLEMENTED",
            "未指定首帧，首帧生成尚未实现",
            stage="preparing_first_frame",
            retryable=False,
        )
    source = _asset_path(agent, document.first_frame_asset_id, "preparing_first_frame")
    root = _gen_dir(agent, work)
    root.mkdir(parents=True, exist_ok=True)
    copied = root / f"first_frame{source.suffix.lower() or '.png'}"
    shutil.copyfile(source, copied)
    width, height = _canvas(agent, document.aspect_ratio)
    fit_image(copied, document.fit, width, height, root / "first_frame_fitted.png")
    _advance(agent, work, "submit_shot")


def _ensure_shots(agent, generation_id: str, document: PlanDocument) -> None:
    with _transaction(agent) as conn:
        count = conn.execute(
            "SELECT COUNT(*) FROM generation_shots WHERE generation_id=?",
            (generation_id,),
        ).fetchone()[0]
        if count:
            return
        for ordinal, shot in enumerate(document.shots):
            conn.execute(
                """INSERT INTO generation_shots (
                    generation_id, shot_id, ordinal, start_frame, end_frame, status,
                    provider_idempotency_key, external_task_id, submission_state, clip_path
                ) VALUES (?, ?, ?, ?, ?, 'pending', NULL, NULL, NULL, NULL)""",
                (generation_id, shot.shot_id, ordinal, shot.start_frame, shot.end_frame),
            )


def _enter(agent, work: dict, step: str) -> None:
    now = agent.clock.now().isoformat()
    with _transaction(agent) as conn:
        total = conn.execute(
            "SELECT COUNT(*) FROM generation_shots WHERE generation_id=?",
            (work["generation_id"],),
        ).fetchone()[0]
        done = conn.execute(
            "SELECT COUNT(*) FROM generation_shots WHERE generation_id=? AND status='imported'",
            (work["generation_id"],),
        ).fetchone()[0]
        conn.execute(
            """UPDATE generations
               SET status='running', stage=?, stage_detail=?, completed_shots=?, total_shots=?, updated_at=?
               WHERE generation_id=?""",
            (_STAGE[step], _DETAIL[step], done, total, now, work["generation_id"]),
        )
        conn.execute(
            """UPDATE tasks
               SET status='generating', stage=?, stage_detail=?, completed_shots=?, total_shots=?, updated_at=?
               WHERE task_id=?""",
            (_STAGE[step], _DETAIL[step], done, total, now, work["task_id"]),
        )


def _advance(agent, work: dict, step: str) -> None:
    with _transaction(agent) as conn:
        conn.execute(
            """UPDATE work_items
               SET step=?, lease_owner=NULL, lease_until=NULL, next_attempt_at=NULL
               WHERE work_id=?""",
            (step, work["work_id"]),
        )


def _fail(agent, work: dict, exc: VideoAgentError) -> None:
    now = agent.clock.now().isoformat()
    stage = exc.stage or _STAGE.get(str(work["step"]))
    details = json.dumps(
        {"shot_ids": exc.shot_ids or [], "fields": exc.fields or [], "details": exc.details or {}},
        ensure_ascii=False,
    )
    retryable = 1 if exc.retryable else 0
    with _transaction(agent) as conn:
        conn.execute(
            """UPDATE generations
               SET status='failed', stage=?, stage_detail=?, failure_code=?, failure_message=?,
                   failure_stage=?, failure_retryable=?, failure_details_json=?, updated_at=?
               WHERE generation_id=?""",
            (stage, exc.message, exc.code, exc.message, stage, retryable, details, now, work["generation_id"]),
        )
        conn.execute(
            """UPDATE tasks
               SET status='failed', stage=?, stage_detail=?, failure_scope='generation',
                   failure_code=?, failure_message=?, failure_stage=?, failure_retryable=?,
                   failure_details_json=?, completed_shots=NULL, total_shots=NULL, updated_at=?
               WHERE task_id=?""",
            (stage, exc.message, exc.code, exc.message, stage, retryable, details, now, work["task_id"]),
        )
        for shot_id in exc.shot_ids or []:
            conn.execute(
                "UPDATE generation_shots SET status='failed' WHERE generation_id=? AND shot_id=?",
                (work["generation_id"], shot_id),
            )
        conn.execute(
            """UPDATE work_items
               SET done=1, lease_owner=NULL, lease_until=NULL, next_attempt_at=NULL
               WHERE work_id=?""",
            (work["work_id"],),
        )


def _load_work(agent, work_id: str) -> dict:
    with _transaction(agent) as conn:
        row = _one(conn, "SELECT * FROM work_items WHERE work_id=?", (work_id,))
    if row is None:
        raise VideoAgentError("NOT_FOUND", "找不到生成工作")
    return row


def _require_generation(agent, generation_id: str) -> dict:

    if row is None:
        raise VideoAgentError("NOT_FOUND", "找不到视频执行")
    return row


def _asset_path(agent, asset_id: str, stage: str) -> Path:
    with _transaction(agent) as conn:
        row = _one(conn, "SELECT relative_path FROM assets WHERE asset_id=?", (asset_id,))
    if row is None:
        raise VideoAgentError("ASSET_MISSING", "素材不存在", stage=stage, retryable=True)
    path = agent.files.path_for(row["relative_path"])
    if not path.is_file():
        raise VideoAgentError("ASSET_MISSING", "素材文件不存在", stage=stage, retryable=True)
    return path


def _canvas(agent, aspect_ratio: str) -> tuple[int, int]:

def _gen_dir(agent, work: dict) -> Path:

def _one(conn, sql: str, params: tuple = ()) -> dict | None:
    cursor = conn.execute(sql, params)
    row = cursor.fetchone()
    if row is None:
        return None
    return {column[0]: row[index] for index, column in enumerate(cursor.description)}

        yield connection

class RecordingVideo:
    def __init__(self, home: Path, extra_frames: int = 0, pending_queries: int = 0) -> None:
        self.home = home
        self.extra_frames = extra_frames
        self.pending_queries = pending_queries
        self.queries = 0
        self.seen: list[tuple] = []
        self._requests: dict[str, ShotRequest] = {}

    def capabilities(self) -> VideoCapabilities:
        return VideoCapabilities(
            native_aspects=["9:16"],
            max_segment_seconds=30,
            supports_first_frame=True,
            supports_reference_images=True,
            supports_tail_frame=True,
        )

    def submit_shot(self, request: ShotRequest) -> SubmitResult:
        connection = sqlite3.connect(self.home / "agent.sqlite")
        row = connection.execute(
            """SELECT provider_idempotency_key, submission_state
               FROM generation_shots WHERE generation_id=? AND shot_id=?""",
            (request.generation_id, request.shot_id),
        ).fetchone()
        self.seen.append((request.shot_id, row))
        external = f"ext-{request.shot_id}"
        self._requests[external] = request
        return SubmitResult(external_task_id=external, uncertain=False)

    def query(self, *, external_task_id: str | None, provider_idempotency_key: str) -> QueryResult:
        del external_task_id, provider_idempotency_key
        self.queries += 1
        if self.queries <= self.pending_queries:
            return QueryResult(state="pending")
        return QueryResult(state="succeeded")

    def download(self, external_task_id: str) -> bytes:
        _need_ffmpeg()
        from video_agent.media import fit_image, still_clip
        import tempfile

        request = self._requests[external_task_id]
        frames = max(1, request.frame_count + self.extra_frames)
        with tempfile.TemporaryDirectory() as directory:
            root = Path(directory)
            image = root / "frame.png"
            fitted = root / "fitted.png"
            clip = root / "clip.mp4"
            Image.open(request.first_frame_path).save(image)
            fit_image(image, request.fit, request.width, request.height, fitted)
            still_clip(fitted, frames, request.width, request.height, clip, video_bitrate=500_000)
            return clip.read_bytes()

def _step_submit_shot(agent, work: dict) -> None:
    _enter(agent, work, "submit_shot")
    shot = _next_shot(agent, work["generation_id"])
    if shot is None:
        _advance(agent, work, "audio")
        return
    if shot["submission_state"] in {"intended", "accepted", "uncertain"}:
        _advance(agent, work, "import_shot")
        return
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    request = _shot_request(agent, work, shot, document)
    _mark_intended(agent, work["generation_id"], shot["shot_id"], request.provider_idempotency_key)
    with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
        try:
            result = agent.video.submit_shot(request)
        except VideoAgentError:
            raise
        except Exception as exc:
            raise VideoAgentError(
                "PROVIDER_TEMPORARY",
                str(exc),
                stage="generating_shots",
                retryable=True,
                shot_ids=[shot["shot_id"]],
            ) from exc
    if result.uncertain or not result.external_task_id:
        _mark_submission(
            agent,
            work["generation_id"],
            shot["shot_id"],
            "uncertain",
            result.external_task_id,
            "pending",
        )
        raise VideoAgentError(
            "PROVIDER_SUBMISSION_UNCERTAIN",
            "无法确认外部任务是否已经创建",
            stage="generating_shots",
            retryable=True,
            shot_ids=[shot["shot_id"]],
        )
    _mark_submission(
        agent,
        work["generation_id"],
        shot["shot_id"],
        "accepted",
        result.external_task_id,
        "submitted",
    )
    _advance(agent, work, "import_shot")


def _step_import_shot(agent, work: dict) -> None:
    _enter(agent, work, "import_shot")
    shot = _next_shot(agent, work["generation_id"])
    if shot is None:
        _advance(agent, work, "audio")
        return
    if not shot["external_task_id"]:
        raise VideoAgentError(
            "PROVIDER_SUBMISSION_UNCERTAIN",
            "无法确认外部任务是否已经创建",
            stage="generating_shots",
            retryable=True,
            shot_ids=[shot["shot_id"]],
        )
    with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
        queried = agent.video.query(
            external_task_id=shot["external_task_id"],
            provider_idempotency_key=shot["provider_idempotency_key"],
        )
    if queried.state == "pending":
        _defer(agent, work)
        return
    if queried.state == "absent":
        raise VideoAgentError(
            "PROVIDER_SUBMISSION_UNCERTAIN",
            "无法确认外部任务是否已经创建",
            stage="generating_shots",
            retryable=True,
            shot_ids=[shot["shot_id"]],
        )
    if queried.state == "failed":
        code = queried.error_code if queried.error_code in _ALLOWED else "PROVIDER_REJECTED"
        raise VideoAgentError(
            code,
            queried.message or "镜头生成失败",
            stage="generating_shots",
            retryable=_RETRYABLE[code],
            shot_ids=[shot["shot_id"]],
        )
    with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
        data = agent.video.download(shot["external_task_id"])
    root = _gen_dir(agent, work)
    dest = root / "shots" / f"{shot['shot_id']}.mp4"
    dest.parent.mkdir(parents=True, exist_ok=True)
    dest.write_bytes(data)
    needed = int(shot["end_frame"]) - int(shot["start_frame"])
    info = probe(dest)
    if info.frame_count < needed:
        raise VideoAgentError(
            "SHOT_DURATION_SHORT",
            "模型片段短于镜头帧区间",
            stage="generating_shots",
            retryable=True,
            shot_ids=[shot["shot_id"]],
        )
    if info.frame_count > needed:
        trimmed = dest.with_suffix(".trim.mp4")
        _trim_clip(dest, needed, trimmed, int(agent.config.video_bitrate))
        os.replace(trimmed, dest)
        info = probe(dest)
        if info.frame_count != needed:
            raise VideoAgentError(
                "MEDIA_EXPORT_FAILED",
                "裁切后帧数仍不等于镜头区间",
                stage="generating_shots",
                retryable=True,
                shot_ids=[shot["shot_id"]],
            )
    relative = dest.relative_to(agent.files.home).as_posix()
    _mark_imported(agent, work["generation_id"], shot["shot_id"], relative)
    if _next_shot(agent, work["generation_id"]) is None:
        _advance(agent, work, "audio")
    else:
        _advance(agent, work, "submit_shot")


def _defer(agent, work: dict) -> None:
    now = agent.clock.now()
    later = (now + timedelta(seconds=1)).isoformat()
    until = (now + timedelta(seconds=int(agent.config.lease_seconds))).isoformat()
    with _transaction(agent) as conn:
        conn.execute(
            """UPDATE work_items
               SET next_attempt_at=?, lease_owner=?, lease_until=?
               WHERE work_id=?""",
            (later, agent.worker_owner, until, work["work_id"]),
        )

def _png(size: tuple[int, int] = (18, 32), color: tuple[int, int, int] = (220, 10, 10)) -> bytes:
    buffer = io.BytesIO()
    Image.new("RGB", size, color).save(buffer, format="PNG")
    return buffer.getvalue()


def _wav() -> bytes:
    raw = struct.pack("<h", 1000) * 16000
    buffer = io.BytesIO()
    with wave.open(buffer, "wb") as handle:
        handle.setnchannels(1)
        handle.setsampwidth(2)
        handle.setframerate(8000)
        handle.writeframes(raw)
    return buffer.getvalue()


def _finish(agent: VideoAgent, task_id: str):
    for _ in range(30):
        view = agent.get_task(task_id)
        if view.status not in {"pending", "planning", "generating"}:
            return view
        agent.tick()
    return agent.get_task(task_id)

def _step_audio(agent, work: dict) -> None:
    _enter(agent, work, "audio")
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    if not document.voiceover and not document.music:
        _advance(agent, work, "compose")
        return
    if document.voiceover and agent.voice is None:
        raise VideoAgentError(
            "PROVIDER_REJECTED",
            "配音已开启，但没有可用的配音实现",
            stage="preparing_audio",
            retryable=True,
        )
    root = _gen_dir(agent, work)
    bitrate = int(agent.config.audio_bitrate)
    if document.voiceover:
        _build_voice(agent, work, document, root, bitrate)
    if document.music:
        _build_music(agent, work, document, root, bitrate)
    _advance(agent, work, "compose")


def _build_voice(agent, work: dict, document: PlanDocument, root: Path, audio_bitrate: int) -> None:
    pieces: list[Path] = []
    cues: list[VoiceCue] = []
    for shot in document.shots:
        window_ms = (shot.end_frame - shot.start_frame) * 1000 // 30
        window_seconds = window_ms / 1000
        segment = root / f"voice-{shot.shot_id}.m4a"
        if window_ms <= 0:
            raise VideoAgentError("MEDIA_EXPORT_FAILED", "镜头帧区间为空", stage="preparing_audio", retryable=True, shot_ids=[shot.shot_id])
        if not shot.voiceover_text.strip():
            _silence(window_seconds, segment, audio_bitrate)
            pieces.append(segment)
            continue
        with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
            result = agent.voice.synthesize(
                text=shot.voiceover_text,
                language=document.language,
                preference=document.voice_preference,
            )
        speed = 1.0
        if result.duration_ms > window_ms:
            speed = result.duration_ms / window_ms
        if speed > 2.0:
            raise VideoAgentError(
                "VOICEOVER_DOES_NOT_FIT",
                "配音文案放不进已确认时长",
                stage="preparing_audio",
                retryable=False,
                shot_ids=[shot.shot_id],
            )
        raw = root / f"voice-{shot.shot_id}.raw.m4a"
        raw.write_bytes(result.audio)
        _atempo_pad(raw, speed, window_seconds, segment, audio_bitrate)
        offset = shot.start_frame * 1000 // 30
        window_end = shot.end_frame * 1000 // 30
        for cue in result.cues:
            start = min(max(int(cue.start_ms / speed) + offset, offset), window_end)
            end = min(max(int(cue.end_ms / speed) + offset, start + 1), window_end)
            cues.append(VoiceCue(text=cue.text, start_ms=start, end_ms=end))
        pieces.append(segment)
    _concat_audio(pieces, root / "voice.m4a", audio_bitrate)
    (root / "cues.json").write_text(
        json.dumps([cue.model_dump() for cue in cues], ensure_ascii=False),
        encoding="utf-8",
    )


def _build_music(agent, work: dict, document: PlanDocument, root: Path, audio_bitrate: int) -> None:
    dest = root / "music.m4a"
    if document.music_asset_id:
        source = _asset_path(agent, document.music_asset_id, "preparing_audio")
        trim_or_loop_audio(source, float(document.duration_seconds), dest, audio_bitrate=audio_bitrate)
        return
    if agent.music is None:
        raise VideoAgentError(
            "PROVIDER_REJECTED",
            "音乐已开启，但没有可用的音乐实现或已登记音频",
            stage="preparing_audio",
            retryable=True,
        )
    with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
        data = agent.music.generate(direction=document.music_direction, duration_seconds=float(document.duration_seconds))
    raw = root / "music.raw.m4a"
    raw.write_bytes(data)
    trim_or_loop_audio(raw, float(document.duration_seconds), dest, audio_bitrate=audio_bitrate)


def _step_compose(agent, work: dict) -> None:
    _enter(agent, work, "compose")
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    clips: list[Path] = []
    with _transaction(agent) as conn:
        rows = conn.execute(
            """SELECT shot_id, status, clip_path FROM generation_shots
               WHERE generation_id=? ORDER BY ordinal""",
            (work["generation_id"],),
        ).fetchall()
    for shot_id, status, clip_path in rows:
        if status != "imported" or not clip_path:
            raise VideoAgentError("MEDIA_EXPORT_FAILED", "镜头片段尚未导入", stage="composing", retryable=True, shot_ids=[shot_id])
        clips.append(agent.files.path_for(clip_path))
    dest = _gen_dir(agent, work) / "composed.mp4"
    concat_clips(clips, dest)
    info = probe(dest)
    if info.frame_count != document.duration_seconds * 30 or info.has_audio:
        raise VideoAgentError(
            "MEDIA_EXPORT_FAILED",
            "拼接后的帧数或音轨不符合无字幕画面",
            stage="composing",
            retryable=True,
        )
    _advance(agent, work, "visual")


def _step_visual(agent, work: dict) -> None:
    _enter(agent, work, "visual")
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    root = _gen_dir(agent, work)
    composed = root / "composed.mp4"
    frames: list[CheckFrame] = []
    for index, shot in enumerate(document.shots):
        positions = {
            "start": shot.start_frame,
            "middle": (shot.start_frame + shot.end_frame - 1) // 2,
            "end": shot.end_frame - 1,
        }
        for position, frame_index in positions.items():
            dest = root / "frames" / f"{shot.shot_id}-{position}.png"
            extract_png(composed, frame_index, dest)
            frames.append(CheckFrame(shot_id=shot.shot_id, position=position, path=dest))
        if index > 0:
            dest = root / "frames" / f"{shot.shot_id}-boundary.png"
            extract_png(composed, shot.start_frame, dest)
            frames.append(CheckFrame(shot_id=shot.shot_id, position="boundary", path=dest))
    if agent.visual is None:
        result = VisualResult(status="not_assessed", reason="visual adapter is none")
    else:
        try:
            result = agent.visual.check(frames, _appearance(document))
        except Exception as exc:
            result = VisualResult(status="not_assessed", reason=str(exc))
    if result.status not in {"passed", "flagged", "not_assessed"}:
        result = VisualResult(status="not_assessed", reason="视觉检查结果无法识别")
    (root / "quality.json").write_text(result.model_dump_json(), encoding="utf-8")
    _advance(agent, work, "export")


def _step_export(agent, work: dict) -> None:
    _enter(agent, work, "export")
    generation = _require_generation(agent, work["generation_id"])
    document = PlanDocument.model_validate_json(generation["snapshot_json"])
    root = _gen_dir(agent, work)
    width, height = _canvas(agent, document.aspect_ratio)
    video_bitrate = int(agent.config.video_bitrate)
    audio_bitrate = int(agent.config.audio_bitrate)
    picture = root / "composed.mp4"
    voice_cues = _read_cues(root / "cues.json")
    if document.subtitles:
        burned = root / "subtitled.mp4"
        burn_subtitles(
            picture,
            _subtitle_cues(document, voice_cues if document.voiceover else None),
            width,
            height,
            burned,
            video_bitrate=video_bitrate,
        )
        picture = burned
    voice = root / "voice.m4a" if document.voiceover else None
    music = root / "music.m4a" if document.music else None
    tmp = root / "final.tmp.mp4"
    try:
        with hold_lease(agent.db, work["work_id"], agent.worker_owner, agent.clock, int(agent.config.lease_seconds)):
            mix_audio(
                picture,
                voice if voice is not None and voice.is_file() else None,
                music if music is not None and music.is_file() else None,
                voice_cues if document.voiceover and document.music else [],
                tmp,
                video_bitrate=video_bitrate,
                audio_bitrate=audio_bitrate,
            )
        _assert_final(tmp, document, agent)
    except Exception:
        if tmp.is_file():
            tmp.unlink()
        raise
    final = root / "final.mp4"
    os.replace(tmp, final)
    _register_artifact(agent, work, generation, document, final)


def _assert_final(path: Path, document: PlanDocument, agent) -> None:
    info = probe(path)
    width, height = _canvas(agent, document.aspect_ratio)
    expected = document.duration_seconds * 30
    if info.frame_count != expected or info.width != width or info.height != height:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "成片帧数或尺寸不符合已确认方案", stage="exporting", retryable=True)
    if info.video_codec != "h264" or _pixel_format(path) != "yuv420p" or abs(_frame_rate(path) - 30) > 0.05:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "成片编码或帧率不符合要求", stage="exporting", retryable=True)
    want_audio = bool(document.voiceover or document.music)
    if info.has_audio != want_audio:
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "成片音轨与开关不一致", stage="exporting", retryable=True)
    if want_audio and info.audio_codec != "aac":
        raise VideoAgentError("MEDIA_EXPORT_FAILED", "成片音轨不是 AAC", stage="exporting", retryable=True)


def _register_artifact(agent, work: dict, generation: dict, document: PlanDocument, final: Path) -> None:
    root = final.parent
    if (root / "quality.json").is_file():
        quality = VisualResult.model_validate_json((root / "quality.json").read_text(encoding="utf-8"))
    else:
        quality = VisualResult(status="not_assessed", reason="缺少视觉检查结果")

def _subtitle_cues(document: PlanDocument, voice_cues: list[VoiceCue] | None) -> list[VoiceCue]:
    cues: list[VoiceCue] = []
    for shot in document.shots:
        if not shot.subtitle_text.strip():
            continue
        window_start = shot.start_frame * 1000 // 30
        window_end = shot.end_frame * 1000 // 30
        if not voice_cues:
            cues.append(VoiceCue(text=shot.subtitle_text, start_ms=window_start, end_ms=window_end))
            continue
        inside = [cue for cue in voice_cues if cue.end_ms > window_start and cue.start_ms < window_end]
        if not inside:
            cues.append(VoiceCue(text=shot.subtitle_text, start_ms=window_start, end_ms=window_end))
            continue
        start = max(window_start, min(cue.start_ms for cue in inside))
        end = min(window_end, max(cue.end_ms for cue in inside))
        if end <= start:
            end = window_end
        cues.append(VoiceCue(text=shot.subtitle_text, start_ms=start, end_ms=end))
    return cues


def _read_cues(path: Path) -> list[VoiceCue]:
    if not path.is_file():
        return []
    return [VoiceCue.model_validate(item) for item in json.loads(path.read_text(encoding="utf-8"))]


def _appearance(document: PlanDocument) -> str:
    visual = document.shared_visual
    parts = [visual.product_reference, visual.character or "", visual.scene, visual.lighting, visual.palette, visual.style]
    return "\n".join(part for part in parts if part)

def _rms_db(path: Path, start: float, duration: float, frequency: int) -> float:
    wav = path.with_name(f"{path.stem}-{start}.wav")
    subprocess.run(
        [
            "ffmpeg", "-y", "-ss", str(start), "-t", str(duration), "-i", str(path),
            "-af", f"bandpass=f={frequency}:width_type=h:width=30",
            "-ac", "1", "-ar", "8000", str(wav),
        ],
        check=True,
        capture_output=True,
        stdin=subprocess.DEVNULL,
    )
    with wave.open(str(wav), "rb") as handle:
        count = handle.getnframes()
        raw = handle.readframes(count)
    samples = struct.unpack("<" + "h" * count, raw)
    mean_square = sum(sample * sample for sample in samples) / count
    return 10 * math.log10(mean_square)
